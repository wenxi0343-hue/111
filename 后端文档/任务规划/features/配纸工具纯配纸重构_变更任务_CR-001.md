## 3. 变更详情

### 新增/修改的验收标准

- **AC-019**: 从原纸管理后台读取在库库存
  - **Given** 服务端已配置后台地址和有效只读令牌
  - **When** 用户生成配纸方案
  - **Then** 系统分页读取全部 `in_stock` 卷纸且不执行任何写操作

- **AC-020**: 车间余料不参与推荐
  - **Given** API 响应混有 `in_stock` 和 `workshop`
  - **When** 适配器映射资料
  - **Then** 只有 `in_stock` 计入汇总和候选

- **AC-021**: 同种原纸按库存重量汇总价格
  - **Given** 同一物料有多卷有效在库数据
  - **When** 适配器生成一条物料资料
  - **Then** 重量求和，吨价按卷重加权平均

- **AC-022**: 后台资料缺失时精确提示
  - **Given** 在库物料无法确定纸种、等级、价格或强度标准
  - **When** 用户生成方案
  - **Then** 该物料被排除并按物料编码展示具体缺失项

- **AC-023**: 后台认证或访问失败时安全停止
  - **Given** Token 缺失、无效或后台不可用
  - **When** 读取库存
  - **Then** 返回安全业务错误且不回退到旧库存

- **AC-024**: 后台令牌不暴露给浏览器
  - **Given** 服务端已配置 Token
  - **When** 页面生成方案
  - **Then** Token 只由服务端适配器使用

### 技术变更

适配器通过依赖注入的 `fetch` 完成只读请求，以便单元测试使用脱敏响应。所有页均明确带
`status=in_stock` 和 `page_size=100`；响应后再次检查状态。数据按 `material_code` 聚合，
价格公式为 `Σ(公斤价×卷重)/Σ卷重×1000`。最终输出既有
`PocketBasePaperMaterialRecord` 兼容形状，以继续复用确定性强度标准和 readiness 缺失项。

无 Token 的当前阶段可以完成全部单元和集成测试；真实联调必须由用户在部署环境中配置一个
仅具业务读取权限、无页面写权限的专用账号 Token，不通过聊天或代码传递。

## 4. 增量任务

> 每个任务按 TDD 循环执行：RED → GREEN → REFACTOR。

### 服务端只读适配

#### Task-14: 后台配置与分页读取契约

**通俗解释**：服务端能够安全地逐页读取后台在库卷纸。

**做什么**：先编写配置缺失、认证失败、分页成功和只发 GET 的失败测试，再实现配置和 HTTP 读取。

**涉及文件**：`src/modules/master-data/warehouse-api-config.ts`、
`src/modules/master-data/warehouse-api-matching-source.ts`、
`tests/unit/master-data/warehouse-api-matching-source.test.ts`

**参考**：本文档 3 → AC-019, AC-023, AC-024

**依赖**：无

**预估工时**：90 分钟

**验证标准**（TDD RED 阶段依据）：
- [x] 两页响应会被完整读取，每个请求都包含 `status=in_stock` 和 `page_size=100`。
- [x] 未配置 Token 返回安全错误，且不调用 `fetch`。
- [x] 401/403 和网络异常返回业务错误，错误中不包含 Token。

**做什么**：先编写混合状态、同物料多卷加权、缺失字段测试，再实现防御性过滤、聚合和字段映射。

**参考**：本文档 3 → AC-020, AC-021, AC-022

**依赖**：Task-14

**预估工时**：120 分钟

**验证标准**（TDD RED 阶段依据）：

`tests/integration/matching/matching-actions.test.ts`

**参考**：本文档 2、3 → AC-019, AC-023, AC-024

**依赖**：Task-15

**预估工时**：90 分钟

**验证标准**（TDD RED 阶段依据）：
- [x] 配置 `WAREHOUSE_API_BASE_URL` 时优先选择原纸后台适配器。

- [x] 未配置后台地址时原有资料源路径保持不变。
- [x] 客户端代码和 `NEXT_PUBLIC_*` 环境变量中不存在后台 Token。
