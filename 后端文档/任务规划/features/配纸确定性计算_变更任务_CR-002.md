## 3. 变更详情

### 新增的验收标准

- **AC-023**: 生成结果摘要显示计算面积
  - **Given** 用户输入合法纸箱参数，且系统生成至少一个带面积结果的推荐或参考方案
  - **When** 用户点击生成方案并查看结果页
  - **Then** 生成结果摘要显示“计算面积”和面积值，不显示“堆码承重”摘要

### 技术变更

页面不新增面积公式，只读取服务端返回的 `recommendationSlots[].evaluation.area.areaSquareMeters`。优先使用第一个带面积结果的槽位；如果没有任何可用面积结果，则显示“暂无面积结果”。

## 4. 增量任务

### 阶段一：调整生成结果摘要

#### Task-09: 生成结果摘要改为面积

**通俗解释**：用户生成方案后，顶部摘要直接看到计算面积，不再看到堆码承重状态。

**做什么**：将 matching 页面生成结果摘要中的 `堆码承重` 改为 `计算面积`；新增展示辅助函数，从推荐槽位中读取首个面积结果；无面积时显示“暂无面积结果”。

**涉及文件**：`src/app/(main)/matching/_components/box-spec-form.tsx`

**参考**：本文档 3 → AC-023

**依赖**：原 Task-06

**预估工时**：25 分钟

**验证标准**（TDD RED 阶段依据）：
- [ ] 服务端返回带面积的推荐槽位 → 页面显示“计算面积”和 `0.8905 m²`
- [ ] 服务端返回堆码层数已填写 → 页面仍显示“计算面积”，不显示“堆码承重”
- [ ] 无可用面积结果 → 页面显示“暂无面积结果”

---

#### Task-10: 回归验证

**做什么**：运行 matching 页面集成测试，确认推荐区、原因汇总和面积摘要仍可用。

**依赖**：Task-09

**验证标准**：
- [ ] `tests/integration/matching/matching-page.test.tsx` 通过
- [ ] 页面不出现堆码承重摘要
- [ ] 页面仍展示推荐卡片内的面积、强度和成本
