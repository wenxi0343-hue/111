# 纸箱输入校验 — 变更记录 CR-001

## 1. 变更概览

**变更标题**：调整纸箱尺寸和层数输入页面  
**变更类型**：扩展  
**变更原因**：重新设计输入流程，当前先完成前端输入。  
**发起日期**：2026-11-07  
**关联功能**：纸箱输入校验

## 2. 影响分析

| 范围 | 变更 |
|------|------|
| 需求 | 新增 AC-021 至 AC-025；旧生成和承重相关 AC 保留为历史，不作为当前阶段验收标准。 |
| 页面 | 内径／外径、三／五／七层选择；移除产品类型、内装物重量及排列方式；暂停生成并解释原因。 |
| 服务端、计算和数据 | 本阶段不改变契约、计算逻辑或存储，也不填入虚构内装物数据。 |
| 现有代码 | `src/app/(main)/matching/_components/box-spec-form.tsx` 已有未验证变更，需检查所有提交路径。 |
| 测试 | `tests/integration/matching/matching-page.test.tsx` 中原字段及生成预期需要按当前阶段调整；相关功能仍需回归。 |

**回归风险**：按钮禁用并不一定阻止回车等表单提交；当前服务端仍要求产品信息，不能视为已支持新输入。既有代码和测试的历史完成记录不代表 CR-001 已验证。

## 3. 变更详情

### 验收标准

完整 Given-When-Then 见 `需求文档/功能需求/纸箱输入校验.md`：

| 编号 | 内容 |
|------|------|
| AC-021 | 默认内径；切换标签并保留数字，不自动换算。 |
| AC-022 | 三层、五层、七层可选，默认三层；页面不显示纸箱结构类型和堆码层数。 |
| AC-023 | 页面不显示三项内装物输入。 |
| AC-024 | 暂停生成并提示，点击或表单提交均不能发起生成。 |
| AC-025 | 本阶段不换算、不产生新计算结果或达标结论。 |

### 后续方向（不属于本任务）

用户已确认外径转内径时各维度按三层减 8 mm、五层减 10 mm、七层减 14 mm；方案仅采用所选层数。内装物输入新位置、指标校验和未校核参考方案的接入另行设计。不得把上述方向误写成本次已实现功能。

## 4. 增量任务

#### [ ] Task-06：核对输入页面

**通俗解释**：用户能选择尺寸口径和纸箱层数，页面不再出现三项内装物输入。

**做什么**：检查已有未验证的页面改动，必要时在实施阶段按验收标准补齐；维持现有无关输入和布局。

**涉及文件**：`src/app/(main)/matching/_components/box-spec-form.tsx`、`tests/integration/matching/matching-page.test.tsx`

**参考**：技术方案“页面表单行为 / CR-001” → AC-021、AC-022、AC-023、AC-025  
**依赖**：原 Task-04  
**预估工时**：60 分钟

**验证标准**：
- [ ] 默认显示内径及三层；切换外径后显示外长、外宽、外高，再切回显示内长、内宽、内高。
- [ ] 输入数字后切换尺寸类型，数字不变；三、五、七层均可选择，页面不显示纸箱结构类型和堆码层数。
- [ ] 页面不显示产品类型、内装物重量或排列方式；其他无关输入保留。
- [ ] 本阶段不发生换算，也不展示新计算或达标结果。

#### [ ] Task-07：暂停所有页面生成入口

**通俗解释**：用户知道计算暂不可用，操作表单也不会误触旧计算。

**做什么**：验证并补齐禁用状态及表单提交保护，不修改后端计算，不使用虚构内装物输入。

**涉及文件**：`src/app/(main)/matching/_components/box-spec-form.tsx`、`tests/integration/matching/matching-page.test.tsx`

**参考**：技术方案“页面表单行为 / CR-001” → AC-024、AC-025  
**依赖**：Task-06、原 Task-03  
**预估工时**：45 分钟

**验证标准**：
- [ ] 页面显示生成暂不可用的说明，生成按钮不可操作。
- [ ] 点击、回车和表单提交均不调用生成动作；不产生方案或达标结论。
- [ ] 不新增后端输入或计算逻辑，不提交虚构的产品信息。

#### [ ] Task-08：回归验证

**通俗解释**：检查调整后的页面和既有功能是否符合当前阶段范围。

**做什么**：运行新增及已有自动化测试、类型检查和代码检查，并在浏览器核对页面；区分受本次阶段变化影响的历史测试与真实故障，不以修改断言掩盖问题。

**参考**：本文第 2、3 节 → AC-021 至 AC-025  
**依赖**：Task-06、Task-07  
**预估工时**：45 分钟

**验证标准**：
- [ ] 新增页面交互和提交保护测试通过，覆盖点击、回车和表单提交。
- [ ] 运行现有完整测试、类型检查和代码检查；记录并处理与本次变更相关的失败，其他失败如实报告。
- [ ] 浏览器核对尺寸类型、层数选择、三项移除和暂停提示。
- [ ] 检查无关页面、后端、计算规则和历史数据未因本变更被改动。
