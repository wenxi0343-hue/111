# 配纸确定性计算_变更任务_CR-003

**变更标题**：纸箱尺寸输入口径改为内径  
**变更日期**：2026-07-04  
**变更类型**：核心公式口径调整  
**变更原因**：用户确认实际业务按纸箱内长、内宽、内高输入，系统不应再按层数扣减尺寸。

## 1. 变更范围

| 模块 | 变更内容 |
|------|----------|
| 面积计算 | `calculateBoardArea` 直接使用输入 L/W/H 作为内径计算展开面积 |
| 输入校验 | 尺寸字段错误提示改为纸箱内长、内宽、内高 |
| 匹配页面 | 输入标签改为纸箱内长、纸箱内宽、纸箱内高 |
| 测试 | 增加五层 BC 粘箱 `425×335×155` 内径面积样例，期望约 `0.8063m²` |
| 文档 | PRD、技术方案和任务规划同步为内径输入口径 |

## 2. 验收标准

- **AC-024**: 纸箱尺寸按内径输入
  - **Given** 用户输入 `L=425,W=335,H=155`，并选择五层 BC 粘箱
  - **When** 系统计算纸板面积
  - **Then** 系统直接按 `425×335×155` 作为内径计算，面积约为 `0.8063m²`

- **AC-025**: 页面输入口径清晰
  - **Given** 用户打开单次配纸页面
  - **When** 查看尺寸输入项
  - **Then** 页面显示纸箱内长、纸箱内宽、纸箱内高

## 3. 回归验证

- 运行面积计算单元测试，覆盖三层、五层、七层面积公式。
- 运行匹配页面集成测试，确认生成结果仍显示计算面积。
- 使用网页预览输入 `425×335×155`，调整为五层 BC 后确认面积约为 `0.8063m²`。
