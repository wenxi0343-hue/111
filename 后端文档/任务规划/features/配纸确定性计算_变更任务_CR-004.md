# 配纸确定性计算 - 变更任务 CR-004

## 变更背景

用户已将原纸库中的纸张按优等品、一等品、合格品标注，希望工具按《三层、五层普通瓦楞纸箱产品物理指标质量标准》中的“基础表”计算耐破、环压等强度指标，而不再要求每张原纸都手工维护耐破指数和横向环压指数。

## 影响范围

- `src/modules/master-data/`：新增原纸强度标准映射，用纸种、等级和克重推导耐破指数、横向环压指数。
- `src/modules/calculations/evaluate-candidate.ts`：瓦楞层不再把耐破指数作为硬性缺失项，仍要求环压指数。
- `tests/unit/master-data/`：覆盖等级推导、缺失等级提示和标准范围缺失提示。

## 验收标准

- [x] 箱板纸 `130g + 合格品` 可推导出耐破指数 `2.4`、横向环压指数 `9.8`。
- [x] 瓦纸 `110g + 一等品` 可推导出耐破指数 `0.65`、横向环压指数 `8.4`。
- [x] 原纸缺少等级时，缺失资料清单提示“缺少等级（优等品、一等品或合格品）”。
- [x] 克重不在质量标准表范围内时，缺失资料清单提示缺少该克重对应的强度标准。
- [x] 瓦楞层不因缺少耐破指数被拦截，仍因缺少横向环压指数被拦截。
