## 3. 变更详情

### 新增/修改的验收标准

- **AC-019**: 直接读取仓库数据库
  - **Given** `DATABASE_URL` 指向可用的 `paper_warehouse`
  - **When** 用户生成配纸方案
  - **Then** 服务端只读 `paper_paperroll` 的在库记录，不发起仓库 API 请求

- **AC-020**: 只使用在库卷纸
  - **Given** 数据库存在在库、车间余料和已出库卷纸
  - **When** 适配器聚合物料
  - **Then** 只有 `status="in_stock"` 的卷纸参与重量与价格计算

- **AC-021**: 使用加权吨价和公司强度标准
  - **Given** 同一物料存在多卷有效重量与公斤价
  - **When** 系统映射推荐原纸
  - **Then** 吨价按卷重加权后乘 1000，耐破和环压按既有纸种、等级、克重标准推导

- **AC-025**: 按公司规则判定等级
  - **Given** 类别或规格包含“进口”“金太阳”“H级”“AA级”或其他文字
  - **When** 系统判定等级
  - **Then** “进口”或“金太阳”为优等品，“H级”或“AA级”为一等品，其余为合格品，且优等品规则优先

### 技术变更

查询仅选择映射需要的字段，并固定 `WHERE status = 'in_stock'`。资料源在一次 Server Action 内缓存读取结果，readiness 和推荐材料仓储共享同一批数据。仓库 Django 表保持只读；既有 Drizzle 迁移只增加配纸工具自己的独立表。

### 兼容性说明

不修改现有 `paper_warehouse` 表和数据。切库前保留 `paper_box_matching`；若需回退，只需恢复原连接串。仓库 API 配置继续保持停用。
