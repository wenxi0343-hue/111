# 历史习惯优先推荐与理由展示 — 变更记录 CR-002

## 1. 变更概览

**变更标题**：公司配纸原则接入候选生成与排序
**变更类型**：扩展
**变更原因**：生成结果不像公司真实配纸习惯，需要把稳定工艺原则结构化接入推荐流程，而不是只依赖历史频率和成本/强度排序。
**发起日期**：2026-07-07
**关联功能**：历史习惯优先推荐与理由展示

## 3. 变更详情

### 新增验收标准

- **AC-020**: 产品类型下拉与贵重物品规则
  - **Given** 用户进入配纸页面
  - **When** 用户选择产品类型
  - **Then** 产品类型只能从常见类型中选择；当选择贵重物品时，推荐候选优先使用优等品面纸

- **AC-021**: 特殊要求结构化读取
  - **Given** 用户在特殊要求中勾选模切工艺或戳穿强度要求
  - **When** 用户生成方案
  - **Then** 服务端读取结构化字段参与推荐规则，不依赖自由文本猜测

- **AC-022**: 瓦纸克重层级规则
  - **Given** 候选方案包含面纸、里纸和瓦纸
  - **When** 系统筛选推荐候选
  - **Then** 瓦纸克重高于面纸或里纸的候选不作为正式推荐，并优先选择瓦纸比面里纸低 20%-40% 的候选

- **AC-023**: 芯纸克重规则
  - **Given** 候选方案包含芯纸
  - **When** 未勾选戳穿强度要求
  - **Then** 系统优先选择低克重芯纸；勾选戳穿强度要求时，芯纸允许提高克重

- **AC-024**: 模切工艺最低面里纸克重
  - **Given** 用户勾选模切工艺
  - **When** 系统生成三层或五层推荐候选
  - **Then** 三层面里纸不得低于 190g，五层面里纸不得低于 200g；不满足的候选不作为正式推荐

### 技术变更

1. 输入层新增稳定契约：

```ts
type ProductType =
  | "食品"
  | "日化"
  | "电子"
  | "五金"
  | "服装"
  | "普通产品"
  | "贵重物品"
  | "其他";

interface BoxSpecialRequirements {
  dieCutting: boolean;
  punctureStrengthRequired: boolean;
  notes?: string | undefined;
}
```

2. 推荐层新增公司配纸原则判断，作用在默认候选和历史候选统一合并之后、评估之前。

3. 公司配纸原则分为硬过滤和软排序：

| 类型 | 规则 |
|------|------|
| 硬过滤 | 瓦纸克重高于面纸或里纸；模切三层面里纸低于 190g；模切五层面里纸低于 200g。 |
| 软排序 | 瓦纸克重比面里纸低 20%-40%；芯纸低克重；贵重物品使用优等品面纸。 |

4. 所有候选仍必须进入 `evaluateMatchingCandidates`，公司配纸原则不得改写成本、强度、达标状态或可生产状态。

### 兼容性说明

旧的 `specialRequirements` 字符串只作为其他说明展示和保存，不参与规则判断。若历史保存记录中没有结构化特殊要求，默认视为未勾选模切工艺、未勾选戳穿强度要求。

## 4. 增量任务

### 阶段一：输入结构化

#### Task-06: 产品类型下拉和特殊要求结构化

**通俗解释**：用户不再靠手写特殊要求让系统猜，页面用下拉和勾选项把规则条件传给系统。

**做什么**：扩展纸箱输入类型和校验；产品类型改为固定可选值；特殊要求改为模切工艺、戳穿强度要求和其他说明。

**涉及文件**：`src/modules/box-spec/types.ts`、`src/modules/box-spec/validate-box-spec.ts`、`src/app/(main)/matching/_components/box-spec-form.tsx`、`tests/unit/box-spec/validate-box-spec.test.ts`、`tests/integration/matching/matching-page.test.tsx`

**参考**：本文档 3 → AC-020, AC-021

**依赖**：无

**预估工时**：120 分钟

**验证标准**：
- [x] 产品类型为空时仍返回字段错误。
- [x] 产品类型不在允许列表时返回字段错误。
- [x] 选择贵重物品时，服务端规范化结果保留 `productType = "贵重物品"`。
- [x] 勾选模切工艺后，服务端规范化结果为 `specialRequirements.dieCutting = true`。
- [x] 勾选戳穿强度要求后，服务端规范化结果为 `specialRequirements.punctureStrengthRequired = true`。

### 阶段二：公司配纸原则候选规则

#### Task-07: 候选生成应用瓦纸、芯纸和模切规则

**通俗解释**：系统先排除明显不符合公司工艺经验的配纸组合，再进入成本和强度校核。

**做什么**：新增公司配纸原则规则函数；默认候选和历史候选统一应用；记录被规则排除或降级排序的原因。

**涉及文件**：`src/modules/recommendation/historical-habit-candidates.ts`、`src/modules/recommendation/scoring.ts`、`src/modules/recommendation/types.ts`、`tests/unit/recommendation/historical-habit-candidates.test.ts`、`tests/unit/recommendation/scoring.test.ts`

**参考**：本文档 3 → AC-022, AC-023, AC-024

**依赖**：Task-06

**预估工时**：180 分钟

**验证标准**：
- [x] 瓦纸克重高于面纸的候选不会成为正式推荐。
- [x] 瓦纸克重高于里纸的候选不会成为正式推荐。
- [x] 多个候选都达标时，优先选择瓦纸低于面里纸 20%-40% 的候选。
- [x] 未勾选戳穿强度要求时，芯纸低克重候选排序更靠前。
- [x] 勾选戳穿强度要求时，芯纸高克重候选允许进入候选集。
- [x] 勾选模切工艺时，三层面里纸低于 190g 的候选不会成为正式推荐。
- [x] 勾选模切工艺时，五层面里纸低于 200g 的候选不会成为正式推荐。

### 阶段三：贵重物品和历史习惯正式接入

#### Task-08: 贵重物品优等品面纸和历史习惯生产路径接入

**通俗解释**：选择贵重物品时，系统优先用更高等级面纸；正式页面路径也真正读取历史习惯，而不只在测试中生效。

**做什么**：正式 `generateMatchingScheme` 路径默认创建真实历史习惯仓储并读取上下文；产品类型为贵重物品时，面纸优先优等品；历史习惯候选也必须遵守公司配纸原则。

**涉及文件**：`src/server/actions/matching-actions.ts`、`src/modules/historical-orders/recommendation-context.ts`、`src/modules/recommendation/historical-habit-candidates.ts`、`tests/integration/matching/matching-actions.test.ts`

**参考**：本文档 3 → AC-020, AC-022, AC-023, AC-024

**依赖**：Task-07

**预估工时**：150 分钟

**验证标准**：
- [ ] 不注入测试函数时，`generateMatchingScheme` 默认读取真实历史习惯仓储。
- [ ] 没有历史习惯批次时，推荐正常回退且不阻断生成。
- [ ] 产品类型为贵重物品且存在优等品箱板纸时，面纸优先使用优等品。
- [ ] 历史习惯候选若违反瓦纸克重或模切最低克重规则，不会成为正式推荐。

**涉及文件**：`src/app/(main)/matching/_components/box-spec-form.tsx`、`tests/integration/matching/matching-page.test.tsx`
