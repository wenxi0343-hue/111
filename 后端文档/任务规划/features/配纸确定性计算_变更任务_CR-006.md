# 配纸确定性计算 - 变更任务 CR-006

## 变更背景

用户确认：超过强度标准表已定义克重范围的原纸，不需要在缺失资料清单中拦截提示，系统应直接默认不采用该纸进行配纸。

## 影响范围

- `src/modules/master-data/pocketbase-matching-readiness.ts`：`strengthStandard` 缺失仍保留在原纸 `missingFields` 中，使该纸保持 `incomplete`，不进入推荐候选。
- `src/modules/master-data/pocketbase-matching-readiness.ts`：缺失资料清单过滤 `strengthStandard`，前台不再因超过标准表克重范围而阻塞生成。
- `tests/unit/master-data/pocketbase-readiness.test.ts`：覆盖超出强度标准表范围时“排除候选但不显示阻塞缺失项”的行为。

## 验收标准

- [x] 原纸克重超过当前强度标准表覆盖范围时，该原纸标记为不完整。
- [x] 原纸克重超过当前强度标准表覆盖范围时，该原纸不进入配纸候选。
- [x] 原纸克重超过当前强度标准表覆盖范围时，缺失资料清单不显示 `strengthStandard` 项。
- [x] 原纸缺少纸价或缺少强度标准时，均按“自动不采用该纸”处理，不阻塞其它可用原纸生成方案。
