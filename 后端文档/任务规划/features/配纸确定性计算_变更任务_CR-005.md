# 配纸确定性计算 - 变更任务 CR-005

## 变更背景

用户确认：缺少纸价的原纸直接默认不采用该纸进行配纸，不需要在缺失资料清单中拦截；缺少对应强度标准时，需要说明具体缺的是什么标准。

## 影响范围

- `src/modules/master-data/pocketbase-matching-readiness.ts`：缺失清单过滤 `priceYuanPerTon`，但原纸仍保持 incomplete，不进入推荐候选。
- `src/modules/master-data/pocketbase-matching-readiness.ts`：`strengthStandard` 缺失文案增加纸种、克重、基础表覆盖范围和影响指标。
- `tests/unit/master-data/pocketbase-readiness.test.ts`：覆盖缺纸价不阻断、强度标准缺失文案。

## 验收标准

- [x] 原纸只缺少纸价时，不出现在缺失资料清单中。
- [x] 原纸只缺少纸价时，仍标记为不完整，不进入配纸候选。
- [x] 瓦纸 `260g` 缺少强度标准时，提示“基础表当前仅覆盖 0-249g”。
- [x] 强度标准缺失提示说明影响“耐破指数和横向环压指数”。
- [x] 页面生成时不再显示“缺少纸价”，只显示仍需补齐的强度标准项。
