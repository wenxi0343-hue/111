# 纸箱输入校验 — 变更记录 CR-002

## 1. 变更概览

**变更标题**：按需展开物理指标输入  
**变更类型**：扩展  
**变更原因**：用户需要在有要求时填写纸箱指标。  
**日期**：2026-11-07  
**关联功能**：纸箱输入校验

## 2. 影响分析

- 新增 AC-026、AC-027；复用当前输入页面和控件。
- 新增可选输入区域：空纸箱重量、内装物重量、堆码层数、边压、耐破、空箱抗压。默认关闭，收起后重新展开保留值。
- 空纸箱和内装物重量暂用 kg，堆码用层、边压用 kN/m、空箱抗压用 N；耐破单位待确认，暂不标注。
- 本阶段只做页面，不修改后端、指标计算和方案生成。既有生成入口继续暂停，原有页面回归已有 25 项失败，需要如实区分记录。

## 3. 变更详情

验收标准详见需求文档 4.5 和 AC-026、AC-027；技术处理详见技术方案“CR-002：物理指标可选输入”。重量与堆码、强度要求分组展示，布局适应窄屏，各项可分别填写；输入仅保存在当前页面，收起再展开保留，刷新持久化不在本次范围。

## 4. 增量任务

### [ ] Task-09：开关和六项输入

**通俗解释**：有要求时展开填写，没有要求时保持页面简洁。

**做什么**：新增开关与六项输入，遵循既有页面风格和确认的单位，收起保留值。

**涉及文件**：`src/app/(main)/matching/_components/box-spec-form.tsx`、`src/app/(main)/matching/matching.module.css`、`tests/integration/matching/box-spec-input-redesign.test.tsx`。

**参考**：需求 4.5、技术方案 CR-002 → AC-026、AC-027  
**依赖**：原 Task-04；与 CR-001 未完成回归并行记录，不修改后端。

**验证标准**：
- [ ] 默认关闭且六项隐藏；开启显示两组和六项输入及已确认单位，耐破不臆造单位。
- [ ] 各项可单独填写；关闭后隐藏，重新开启保留数值。
- [ ] 窄屏不溢出；不触发方案生成，不提交或校验指标。

### [ ] Task-10：页面验收

**通俗解释**：在实际页面检查布局和展开操作是否符合使用习惯。

**参考**：AC-026、AC-027  
**依赖**：Task-09。

**验证标准**：
- [ ] 浏览器检查默认、展开、填写、收起、再展开及窄屏显示。
- [ ] 页面已有输入保持可用，方案生成仍暂停。

### [ ] Task-11：回归验证

**做什么**：执行新增测试及相关检查，检查完整测试并如实记录已有失败。

**依赖**：Task-09、Task-10。

**验证标准**：
- [ ] 新增交互测试、类型检查和代码检查通过。
- [ ] 检查既有测试，区分历史 25 项页面测试失败及新增问题，不删除测试掩盖失败。
- [ ] 未修改现有计算公式或后端数据契约。
