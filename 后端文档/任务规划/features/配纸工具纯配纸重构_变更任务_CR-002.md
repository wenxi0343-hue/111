## 3. 变更详情

### 新增/修改的验收标准

- **AC-019**: 从 PostgreSQL 读取配纸资料
  - **Given** `DATABASE_URL` 可用且数据库资料完整
  - **When** 用户生成配纸方案
  - **Then** 系统通过 Drizzle 读取资料并生成方案，不请求仓库后台 API

- **AC-020**: 只使用启用且完整的原纸
  - **Given** 数据库同时存在启用完整、停用和不完整原纸
  - **When** 系统读取推荐材料
  - **Then** 只有启用且 `complete` 的原纸进入候选

- **AC-023**: 数据库不可用时安全停止
  - **Given** `DATABASE_URL` 缺失、凭证无效或数据库不可访问
  - **When** 用户生成方案
  - **Then** 返回脱敏数据库错误，且不调用仓库后台 API

- **AC-024**: 数据库连接信息不暴露给浏览器
  - **Given** 服务端配置了 `DATABASE_URL`
  - **When** 用户打开页面或生成方案
  - **Then** 客户端代码、请求和业务错误均不包含连接串或密码

### 技术变更

默认仓储上下文通过 `getDatabaseUrl` 与 `createDatabaseClient` 创建 Drizzle 客户端，同一
`db` 实例交给资料完整性仓储和推荐原纸仓储。测试仍可注入内存仓储，不要求连接真实数据库。
仓库 API 适配器、配置项和专属测试从当前产品范围移除。

### 兼容性说明

数据库表结构和历史方案快照不变，无需迁移。部署环境必须提供有效 `DATABASE_URL`；原有
`WAREHOUSE_API_*` 配置即使仍存在也不再读取。
