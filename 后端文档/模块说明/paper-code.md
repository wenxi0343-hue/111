# paper-code

原纸代码映射模块。必须精确匹配并区分大小写，支持 `aδ` 等历史代码。

## 能力边界

- `matchPaperCode` 用于单个原纸代码映射，返回精确匹配、大小写候选、疑似克重、空代码或无法匹配状态。
- `matchPaperCodes` 用于批量映射，逐条保留原始输入顺序，并返回可用于导入预览的汇总结果。
- `matchPaperCodeExactly` 是兼容入口，只在精确匹配成功时返回原纸。

大小写候选只用于提示人工确认，不会被自动替换为匹配成功。本模块不导入历史订单，不创建或修改原纸资料，也不依赖页面、Server Action 或数据库。
