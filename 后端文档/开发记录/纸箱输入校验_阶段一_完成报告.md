## 2. 本阶段完成内容

- 新增 `BoxSpecInput`、`NormalizedBoxSpec`、堆码参与状态和字段错误类型。
- 新增纸箱输入范围常量，集中管理尺寸、重量、堆码层数和长宽比例边界。

- 新增 `isStackingRequired`，给后续强度和推荐模块判断承重是否参与本次方案。
- 更新 `box-spec` 模块说明，明确不保留堆码总高度，不做面积、强度、成本和推荐。

## 3. 覆盖的验收标准

| AC | 覆盖情况 |
|----|----------|
| AC-001 | 合法完整输入可通过 `validateBoxSpecInput`。 |
| AC-002 | 未填写堆码层数时返回 `not_required`，不阻止生成流程。 |
| AC-003 | 填写合法堆码层数时返回 `required`。 |
| AC-004 | 未填写堆码层数时输出“未填写堆码层数，承重未校核”。 |
| AC-005 | 必填字段为空时返回字段级错误。 |
| AC-006 | 尺寸、重量、生产数量超范围时返回字段级错误。 |
| AC-007 | 长度小于宽度时返回明确错误。 |
| AC-008 | 长宽比例大于 5.0 时返回明确错误。 |
| AC-009 | 堆码层数超出 1-30 层时返回字段级错误。 |
| AC-012 到 AC-016 | 边界值、尺寸范围、重量范围、堆码范围、生产数量规则已覆盖。 |
| AC-017 | 类型和模块中不包含堆码总高度字段。 |
| AC-018 / AC-019 | 通过 `stackingRequirement.status` 区分承重是否参与判断。 |
| AC-020 | 本阶段未新增数据库表、第三方依赖、页面范围外能力或核心公式。 |
