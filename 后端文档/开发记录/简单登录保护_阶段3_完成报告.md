## 问题与决策

### 完成报告模板缺失

**处理**：沿用已有 `docs/开发记录/简单登录保护_阶段1_完成报告.md` 的格式生成本阶段报告。

### 退出入口采用客户端按钮

**情况**：`logout` 是 Server Action，但用户点击退出后还需要在客户端回到登录页并刷新路由状态。

**处理**：新增小型客户端组件 `LogoutButton`，复用现有登录表单的 `router.replace()` + `router.refresh()` 模式。

**影响**：主布局仍保留服务端会话保护逻辑，交互逻辑集中在按钮组件中。
