# 公司配纸原则接入推荐设计

## 背景

当前“历史习惯优先推荐与理由展示”已经具备历史摘要、历史候选、匹配等级和三类方案排序的设计，但用户反馈生成结果仍不像公司真实配纸习惯。经确认，缺口不只是历史频率排序，还缺少公司稳定工艺原则对候选生成的约束。

本设计把这些原则作为候选生成和排序规则接入推荐流程，保持现有硬规则边界：面积、强度、成本和设备限制仍由 `calculations` 负责，历史习惯和公司配纸原则不得改写计算结果。

## 已确认口径

- `产品类型` 改为下拉菜单，包含食品、日化、电子、五金、服装、普通产品、贵重物品、其他等常见类型。
- 只有产品类型为 `贵重物品` 时，触发“面纸优先优等品”规则。
- `特殊要求` 改为结构化勾选项加其他说明，系统只读取结构化字段参与推荐规则。
- 结构化特殊要求首版包括 `模切工艺` 和 `戳穿强度要求`。
- 瓦纸克重应低于面纸和里纸，优先低 20%-40%；瓦纸克重高于面纸或里纸的候选不作为正式推荐。
- 芯纸默认优先低克重；只有勾选 `戳穿强度要求` 时，芯纸允许提高克重。
- 勾选 `模切工艺` 时，三层面里纸不低于 190g，五层面里纸不低于 200g。

## 设计

### 输入模型

在 `BoxSpecInput` 和 `NormalizedBoxSpec` 中保留 `productType` 字段，但把前端自由输入改为固定下拉。新增结构化 `specialRequirements` 数据，不再把它作为仅供展示的自由文本。建议契约：

```ts
interface BoxSpecialRequirements {
  dieCutting: boolean;
  punctureStrengthRequired: boolean;
  notes?: string | undefined;
}
```

兼容现有数据时，旧字符串可作为 `notes` 处理，但推荐规则只读取布尔字段。

### 候选规则

在 `src/modules/recommendation/` 新增或扩展候选规则层，对默认候选和历史习惯候选统一应用：

- 结构约束：按层位读取面纸、里纸、瓦纸、芯纸。
- 克重约束：瓦纸克重必须小于面纸和里纸；优先排序落在低 20%-40% 区间的候选。
- 芯纸约束：未要求戳穿强度时，芯纸在满足强度校核前提下优先低克重。
- 模切约束：模切三层候选面里纸不低于 190g；模切五层候选面里纸不低于 200g。
- 贵重物品约束：产品类型为贵重物品时，面纸优先使用优等品。

这些规则不直接给出成本、强度或达标结论。所有候选仍进入 `evaluateMatchingCandidates` 重新校核。

### 排序

建议把规则分成两类：

- 硬过滤：瓦纸高于面/里纸、模切最低面里纸克重不足。
- 软排序：瓦纸低 20%-40% 区间、芯纸低克重、贵重物品优等面纸。

经济型、安全型、均衡型仍保留原定位；公司配纸原则只影响候选进入顺序和同类候选排序。

### 展示

页面只展示用户可理解的说明：

- 产品类型为贵重物品时，说明面纸优先采用优等品。
- 模切工艺时，说明面里纸最低克重要求已参与筛选。
- 戳穿强度要求时，说明芯纸克重策略已放宽。
- 不展示内部裸分。

## 测试重点

- 产品类型下拉只提交允许值。
- 特殊要求勾选项会进入服务端校验后的规范化输入。
- 瓦纸克重高于面纸或里纸的候选不会成为正式推荐。
- 模切三层面里纸低于 190g、五层低于 200g 的候选不会成为正式推荐。
- 贵重物品候选优先选择优等品面纸。
- 戳穿强度未要求时芯纸优先低克重；要求时允许更高克重。
- 历史习惯可用时，历史候选也必须遵守上述公司配纸原则。
