## 2. 产品定位

纸箱自动配纸工具面向纸箱厂工艺人员和销售业务员，用于客户询价、报价和打样前的单次配纸决策。

用户输入纸箱尺寸、内装物、堆码、生产数量等信息后，系统基于公司默认面积公式、强度公式、成本公式和原纸数据，自动生成经济型、安全型、均衡型方案，并输出成本、耐破、边压、空箱抗压、是否达标、是否可生产和选型理由。

## 3. 当前开发边界

当前项目以 MVP 核心闭环为主：

1. 维护纸厂、原纸和基础参数。
2. 输入纸箱参数、产品信息、堆码要求和生产数量。
3. 进行面积、强度、成本和设备限制的确定性计算。
4. 生成经济型、安全型、均衡型三套推荐方案。
5. 支持用户手动调整方案并重新校核。
6. 保存最近 50 条历史方案。

首版不做批量配纸、多用户复杂权限、供应商价格自动同步、客户信息关联、方案版本对比、摇盖专项校验、戳穿强度或吸潮变形等其他指标。

## 4. 确定性计算口径

面积、强度、成本和设备限制是产品可信度核心，必须优先遵守 PRD 第 8.2-8.10 的规则。

本阶段已确认：

- 面积公式按 PRD 第 8.2 固化。
- 生产设备限制按 PRD 第 8.3 固化。
- 强度公式按 PRD 第 8.4-8.7 固化。
- 成本公式按 PRD 第 8.8-8.10 固化。
- Excel 成本表、纸价表或历史订单表仅作为样例核对来源，不反推或新增公式口径。
- 如果样例数据与 PRD 公式不一致，应先记录差异并向用户确认，不得自行修改公式。

## 5. 模块归属

确定性计算相关能力归属 `src/modules/calculations/`：

- 三层、五层、七层面积计算。
- 七层两片成箱面积计算。
- 设备尺寸限制校验。
- 耐破、边压、空箱抗压计算。
- 原纸利用率计算。
- 用纸总价、加工费用、税金、含税成本计算。

推荐策略归属 `src/modules/recommendation/`，不得把不达标或不可生产方案推荐为达标方案。

页面只负责输入、展示和触发操作，不承载核心业务公式。

## 6. 开发约束

- 所有改动应保持小范围、易审查。
- 不得新增与 `后端文档/项目规范/项目结构.md` 冲突的顶层模块。
- 公式、推荐、原纸代码映射等高风险业务必须补充测试。
- 涉及真实订单、纸价、客户或原纸数据时，不得复制到公开样例或测试快照，必要时必须脱敏。
- AI 只能生成选型理由或辅助说明，不参与核心计算，不反写计算结果。
