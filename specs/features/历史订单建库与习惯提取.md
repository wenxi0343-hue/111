# 历史订单建库与习惯提取 — 功能需求说明书

## 1. 背景与价值

**为什么做**：纸箱自动配纸工具已经具备原纸代码映射、原纸资料建库、确定性计算和推荐策略等基础能力。下一步需要把近三年历史订单整理成可查询、可清洗、可统计的订单资料，让系统能够看见公司过往真实配纸习惯，而不是只依赖单次计算结果。

**做成什么样**：用户导入近三年订单数据后，系统识别订单关键字段，清洗纸质/配纸代码，形成成功、待确认、异常和失败清单；只有关键字段完整且纸质代码明确匹配的订单参与习惯统计，最终输出按产品、尺寸区间和重量区间归纳的常用层数、瓦型、纸厂和克重组合摘要。

**关联**：`specs/开发路线图.md` Milestone 2 / Phase 2.1 / 历史订单建库与习惯提取；为后续“历史习惯评分与理由展示”提供输入，但本功能不直接影响推荐排序。

## 2. 范围

### 本次做

- 导入近三年历史订单数据。
- 识别订单日期、纸箱尺寸、产品名称或类别、生产数量、纸质/配纸代码等关键字段。
- 使用既有原纸代码映射规则清洗纸质/配纸代码。
- 识别空纸质、单代码、双代码、无法匹配、疑似大小写错误、疑似克重误填等异常。
- 异常订单仍可入库，但标记为待确认或异常，暂不参与习惯统计。
- 缺少关键字段的订单进入失败清单，不进入历史订单库。
- 统计可参与习惯分析的订单，输出按产品名称/类别、尺寸区间、重量区间的配纸习惯摘要。
- 展示常用层数、瓦型、纸厂、克重组合及出现频率。
- 统计产品名称或类别维度的偏好，但不建立客户信息关联。

### 本次不做

- 不做历史习惯参与推荐排序 — 后续“历史习惯评分与理由展示”单独处理。
- 不做客户信息关联 — PRD V1.0 明确不包含客户信息关联。
- 不做客户偏好推荐 — 避免变相引入客户档案能力。
- 不做成本趋势分析 — 属于后续运营分析能力。
- 不做批量配纸 — PRD V1.0 明确不包含。
- 不把历史价格、历史成本或历史公式口径当作当前成本结论。
- 不修改现有面积、强度、成本、设备限制或推荐规则。

## 4. 需求详述

### 4.1 核心流程

1. 用户进入历史订单导入页面。
2. 用户上传近三年历史订单数据文件。
3. 系统识别订单日期、纸箱尺寸、产品名称或类别、生产数量、纸质/配纸代码等关键字段。
4. 系统预览导入结果，展示成功、待确认、异常和失败数量。
5. 系统使用原纸代码映射规则清洗纸质/配纸代码。
6. 用户查看异常清单和失败清单，确认本次导入。
7. 系统将可入库订单保存为历史订单资料，并标记是否可参与习惯统计。
8. 系统基于可统计订单生成产品、尺寸和重量维度的配纸习惯摘要。

### 4.2 交互规则

- 上传后必须先展示预览，不允许静默导入。
- 预览结果必须展示成功入库数量、可统计数量、待确认数量和失败数量。
- 失败行必须展示可理解的失败原因。
- 待确认或异常订单必须展示原始纸质/配纸代码、异常原因和候选项。
- 纸质代码存在候选时，只能提示用户确认，不自动替换为候选代码。
- 用户取消导入确认时，本次预览内容不进入历史订单库。
- 习惯摘要按出现频率从高到低展示常用组合。
- 重量字段可识别时进入重量区间统计；缺少重量的订单不进入重量区间统计，但不影响其在产品和尺寸维度的统计。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 关键字段包括订单日期、纸箱尺寸、产品名称或类别、生产数量、纸质/配纸代码。 |
| BR-002 | 缺少关键字段的订单进入失败清单，不进入历史订单库。 |
| BR-003 | 纸质/配纸代码清洗必须复用既有原纸代码映射规则，包括大小写敏感、特殊代码、疑似克重和多候选处理。 |
| BR-004 | 纸质代码异常或需要人工确认的订单可入库，但暂不参与习惯统计。 |
| BR-005 | 只有关键字段完整且纸质代码明确匹配的订单参与习惯统计。 |
| BR-006 | 习惯摘要按产品名称/类别、尺寸区间、重量区间统计常用层数、瓦型、纸厂和克重组合。 |
| BR-007 | 重量区间按 `≤20kg`、`20-30kg`、`≥30kg` 统计，与现有三层、五层、七层推荐规则保持一致。 |
| BR-008 | 尺寸区间首版按小箱、中箱、大箱统计，边界由历史订单分布生成预览，用户确认后作为本次统计口径。 |
| BR-009 | 历史订单中的价格、成本或历史公式口径不能作为当前成本结论。 |
| BR-010 | 历史习惯只能作为后续推荐排序参考，不能覆盖强度、成本和设备限制等硬规则。 |
| BR-011 | 本功能不建立客户信息关联，不输出客户偏好推荐。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 识别历史订单字段
  - **Given** 用户上传近三年订单数据文件
  - **When** 系统识别文件内容
  - **Then** 页面展示可识别的订单日期、纸箱尺寸、产品名称或类别、生产数量、纸质/配纸代码字段

- [ ] **AC-002**: 明确匹配订单可统计
  - **Given** 订单行关键字段完整且纸质/配纸代码能精确匹配
  - **When** 用户确认导入
  - **Then** 该订单进入历史订单库，并标记为可参与习惯统计

- [ ] **AC-003**: 展示习惯摘要
  - **Given** 历史订单中存在可统计订单
  - **When** 用户查看习惯摘要
  - **Then** 页面按产品名称/类别、尺寸区间、重量区间展示常用层数、瓦型、纸厂和克重组合

- [ ] **AC-004**: 常用组合按频率排序
  - **Given** 同一统计维度下存在多种配纸组合
  - **When** 系统生成习惯摘要
  - **Then** 页面按出现频率从高到低展示常用组合

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-005**: 关键字段缺失进入失败清单
  - **Given** 某订单缺少订单日期、纸箱尺寸、产品名称或类别、生产数量、纸质/配纸代码中的关键字段
  - **When** 系统预览导入结果
  - **Then** 该行进入失败清单，并展示缺失原因

- [ ] **AC-006**: 纸质代码异常订单可入库但不参与统计
  - **Given** 某订单纸质/配纸代码为空、单代码、双代码、无法匹配、疑似大小写错误或疑似克重误填
  - **When** 系统清洗订单
  - **Then** 该订单仍可入库，但标记为待确认或异常，暂不参与习惯统计

- [ ] **AC-007**: 候选代码不自动替换
  - **Given** 某订单纸质/配纸代码存在大小写候选或多个候选
  - **When** 用户查看异常清单
  - **Then** 页面展示原始代码、异常原因和候选项，不自动替换为候选代码

- [ ] **AC-008**: 导入结果数量可见
  - **Given** 历史订单中同时存在可统计、待确认、异常和失败订单
  - **When** 用户查看导入结果
  - **Then** 页面分别展示成功入库数量、可统计数量、待确认数量和失败数量

- [ ] **AC-009**: 取消导入不保存预览
  - **Given** 用户已查看历史订单导入预览
  - **When** 用户取消导入确认
  - **Then** 本次预览内容不进入历史订单库

- [ ] **AC-010**: 缺少重量不影响其他维度统计
  - **Given** 某订单关键字段完整、纸质/配纸代码明确匹配，但缺少重量信息
  - **When** 系统生成习惯摘要
  - **Then** 该订单不进入重量区间统计，但仍可进入产品名称/类别和尺寸区间统计

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-011**: 只有明确匹配订单参与统计 ← BR-005
  - **Given** 历史订单已导入
  - **When** 系统生成习惯摘要
  - **Then** 只有关键字段完整且纸质/配纸代码明确匹配的订单参与统计

- [ ] **AC-012**: 历史成本不作为当前结论 ← BR-009
  - **Given** 历史订单中的价格、成本或历史公式口径与当前不一致
  - **When** 系统提取配纸习惯
  - **Then** 不把历史价格或历史成本当作当前成本结论

- [ ] **AC-013**: 历史习惯不得覆盖硬规则 ← BR-010
  - **Given** 系统生成历史习惯摘要
  - **When** 后续推荐功能读取这些结果
  - **Then** 历史习惯只能作为后续排序参考，不能覆盖强度、成本、设备限制等硬规则

- [ ] **AC-014**: 不扩大到推荐排序和客户关联 ← BR-011
  - **Given** 本功能完成后
  - **When** 检查功能范围
  - **Then** 不包含历史习惯参与推荐排序、客户档案关联、客户偏好推荐或成本趋势分析

- [ ] **AC-015**: 产品维度不等于客户关联 ← BR-011
  - **Given** 用户查看历史习惯摘要
  - **When** 页面展示产品维度统计
  - **Then** 可以按产品名称或类别展示偏好，但不建立客户信息关联

- [ ] **AC-016**: 重量区间口径固定 ← BR-007
  - **Given** 订单中存在可识别重量信息
  - **When** 系统生成重量维度习惯摘要
  - **Then** 按 `≤20kg`、`20-30kg`、`≥30kg` 展示统计结果

- [ ] **AC-017**: 尺寸区间需确认 ← BR-008
  - **Given** 系统根据历史订单分布生成小箱、中箱、大箱尺寸区间预览
  - **When** 用户确认本次统计口径
  - **Then** 系统按确认后的尺寸区间展示尺寸维度习惯摘要
