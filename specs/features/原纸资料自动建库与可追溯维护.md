# 原纸资料自动建库与可追溯维护 — 功能需求说明书

## 1. 背景与价值

**为什么做**：项目后续配纸计算、推荐方案和成本核算都依赖可用的原纸资料库。现有资料分散在多份表格中：原纸代码表提供原纸身份，纸价表提供历史和当前价格，物理指标/标准表提供强度和标准参数。用户希望系统能导入这些表格后自动检索关联，建立可用于后续配纸的资料库，而不是只靠一次性手工录入。

**做成什么样**：用户导入现有表格后，系统自动识别原纸、供应商、价格、强度指标和资料完整性，生成新增、更新、待确认、失败清单；确认后形成当前可用资料库，并保留后续更新的变更历史。

**关联**：`specs/开发路线图.md` Milestone 1 / Phase 1.2 / 纸厂与原纸主数据；部分提前承接 Phase 2.1 / 原纸 Excel/CSV 导入的最小建库能力。

---

## 2. 范围

### 本次做

- 导入原纸代码表，建立原纸基础档案。
- 导入纸价表，自动检索并关联到已有原纸档案。
- 导入物理指标/标准表，补充纸类、强度指标或标准参数所需信息。
- 页面允许用户选择原纸代码表、纸价表、物理指标/标准表三种导入来源，并使用同一预览、待确认和确认入库闭环。
- 自动建立或匹配纸厂资料，纸厂来源优先使用原纸供应商简称。
- 按原纸代码建立唯一原纸档案；原纸编码只作为辅助关联字段。
- 导入前展示预览，区分新增、更新、待确认、失败、资料不完整。
- 对无法唯一确定的关联进入待确认清单，不允许静默猜测入库。
- 用户确认后才正式入库。
- 后续再次导入同一原纸代码时，更新当前资料并保留变更记录。
- 支持导入后手工编辑、启用/停用、查看修改历史。

### 本次不做

- 不导入近三年订单数据 — 该文件用于后续“历史订单导入与清洗”和历史习惯分析。
- 不做历史配纸习惯提取 — 依赖历史订单清洗结果，后续单独设计。
- 不做一键恢复旧版本 — 恢复旧值可作为一次新的修改，后续再增强。
- 不做审批流程 — 首版修改和确认入库后立即生效。
- 不做供应商价格自动同步 — PRD V1.0 明确不包含。
- 不做完整导出备份 — 原纸、公式/参数、历史方案导出属于后续 `import-export` 范围。

## 4. 需求详述

### 4.1 核心流程

1. 用户进入主数据导入建库页面。
2. 用户上传原纸代码表，系统识别原纸代码、原纸编码、克重、原纸供应商简称和原纸名称。
3. 系统检查原纸代码唯一性，生成新增、更新、失败和资料不完整预览。
4. 用户确认后，系统建立原纸基础档案和纸厂资料。
5. 用户继续上传纸价表或物理指标/标准表。
6. 系统按原纸代码、原纸编码、供应商简称 + 原纸名称 + 克重等顺序自动检索关联。
7. 唯一确定的关联进入新增或更新预览；无法唯一判断的记录进入待确认清单；无法处理的记录进入失败清单。
8. 用户确认待确认项后，系统入库并记住确认过的关联关系。
9. 导入完成后，用户查看原纸资料库，能看到资料完整性、启用状态和修改历史。

### 4.2 交互规则

- 导入前必须先预览，不允许上传后直接静默入库。
- 导入来源必须由用户显式选择，页面需支持原纸代码表、纸价表、物理指标/标准表。
- 预览结果必须按新增、更新、待确认、失败、资料不完整分组展示。
- 失败行必须展示可理解的失败原因。
- 待确认项必须展示候选原纸和不确定原因。
- 用户确认入库前，可以取消本次导入。
- 用户确认过的关联关系，后续同类导入优先复用。
- 修改影响计算或推荐的字段时，必须填写修改原因。
- 停用原纸后，该原纸不再参与新方案推荐，但仍可在历史和变更记录中查看。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 原纸代码是原纸的唯一业务标识，全局不允许重复。 |
| BR-002 | 原纸编码可能重复，只能作为辅助关联字段，不能作为唯一标识。 |
| BR-003 | 导入内容一律视为不可信输入，必须校验字段、格式、数值和关联结果。 |
| BR-004 | 自动关联的优先级为：原纸代码精确匹配 → 原纸编码辅助匹配 → 供应商简称 + 原纸名称 + 克重组合匹配。 |
| BR-005 | 组合匹配只有在唯一确定时才能自动关联；存在多个候选时必须进入待确认。 |
| BR-006 | 资料不完整的原纸可以保存，但不得参与正式推荐。 |
| BR-007 | 原纸和纸厂首版不做物理删除，只支持启用/停用。 |
| BR-008 | 再次导入同一原纸代码时视为更新当前资料，必须保留变更记录。 |
| BR-009 | 纸价、克重、用途、适用瓦型、耐破指数、横向环压指数、启用/停用状态变化时必须填写修改原因。 |
| BR-010 | 历史方案后续保存的是当时快照，不得被主数据后续更新覆盖。 |
| BR-011 | 近三年订单数据不参与本功能建库，后续由历史订单导入与清洗功能处理。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 上传原纸代码表并识别字段
  - **Given** 用户已登录并位于主数据导入建库页面
  - **When** 用户上传包含原纸代码、原纸编码、克重、原纸供应商简称、原纸名称的原纸代码表
  - **Then** 系统展示字段识别结果，并提示该表可用于建立原纸基础档案

- [ ] **AC-002**: 预览原纸基础档案新增结果
  - **Given** 原纸代码表中的原纸代码均未在当前资料库中存在
  - **When** 用户查看导入预览
  - **Then** 系统在新增清单中展示即将建立的原纸档案数量和纸厂数量

- [ ] **AC-003**: 确认后建立原纸和纸厂资料
  - **Given** 用户已查看原纸代码表导入预览，且没有阻断性失败
  - **When** 用户确认入库
  - **Then** 系统建立原纸基础档案和纸厂资料，并在原纸列表中展示这些资料

- [ ] **AC-004**: 导入纸价表并自动关联唯一原纸
  - **Given** 系统中已存在原纸基础档案
  - **When** 用户上传纸价表，且某条纸价记录能唯一关联到一张原纸
  - **Then** 系统在更新预览中展示该原纸将补充或更新的纸价信息

- [ ] **AC-005**: 导入物理指标/标准表并补充资料
  - **Given** 系统中已存在原纸基础档案
  - **When** 用户上传物理指标或标准表，且某条记录能唯一关联到一张原纸或明确适用的纸类规则
  - **Then** 系统在预览中展示将补充的纸类、强度指标或标准参数信息

- [ ] **AC-006**: 再次导入同一原纸代码更新当前资料
  - **Given** 某原纸代码已存在于资料库
  - **When** 用户再次导入包含该原纸代码且字段值发生变化的表格
  - **Then** 系统将该行归入更新清单，并展示变化字段

- [ ] **AC-007**: 用户确认待确认关联
  - **Given** 某导入记录进入待确认清单，且系统展示了候选原纸
  - **When** 用户选择正确原纸并确认
  - **Then** 系统将该记录关联到用户确认的原纸，并在后续同类导入中优先复用该确认关系

- [ ] **AC-008**: 查看资料完整性
  - **Given** 导入完成后存在部分资料完整、部分资料不完整的原纸
  - **When** 用户查看原纸资料库
  - **Then** 系统清楚标记每张原纸是否可用于正式推荐，以及缺少哪些资料

- [ ] **AC-009**: 导入后手工维护原纸
  - **Given** 某原纸已通过导入建立档案
  - **When** 用户手工编辑该原纸的资料字段并保存
  - **Then** 系统更新当前资料，并生成一条修改历史

- [ ] **AC-026**: 多来源导入页面闭环
  - **Given** 用户已登录并位于主数据导入建库页面，系统中已有原纸基础档案
  - **When** 用户选择“纸价表”或“物理指标/标准表”并上传对应 `.xlsx` / `.csv` 文件
  - **Then** 系统按所选来源生成预览，展示更新、待确认、失败或标准规则结果；待确认行可在页面选择候选原纸并确认；最终确认入库后写入当前资料、价格历史或质量标准及变更历史

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-010**: 原纸代码重复
  - **Given** 导入文件中存在重复原纸代码，或导入记录与已有原纸代码冲突且不是同一原纸更新
  - **When** 用户查看导入预览
  - **Then** 系统将相关记录标记为失败，并提示原纸代码重复，阻止这些记录入库

- [ ] **AC-011**: 原纸编码重复不作为失败
  - **Given** 导入文件中存在重复原纸编码，但原纸代码不同
  - **When** 用户查看导入预览
  - **Then** 系统不因原纸编码重复直接判定失败，并提示原纸编码仅作为辅助关联字段

- [ ] **AC-012**: 无法唯一关联进入待确认
  - **Given** 纸价表或物理指标表中的某条记录无法通过原纸代码或原纸编码唯一关联，且组合信息匹配到多个候选原纸
  - **When** 用户查看导入预览
  - **Then** 系统将该记录放入待确认清单，并展示多个候选项和不确定原因

- [ ] **AC-013**: 无可用关联进入失败
  - **Given** 某导入记录缺少足够信息，无法找到任何可关联原纸
  - **When** 用户查看导入预览
  - **Then** 系统将该记录放入失败清单，并提示无法关联原纸

- [ ] **AC-014**: 必填字段缺失
  - **Given** 原纸代码表中某行缺少原纸代码、克重、原纸供应商简称或原纸名称
  - **When** 用户查看导入预览
  - **Then** 系统将该行标记为失败，并指出缺失字段

- [ ] **AC-015**: 数值字段非法
  - **Given** 导入记录中的克重、纸价、耐破指数或横向环压指数不是有效数值
  - **When** 用户查看导入预览
  - **Then** 系统将该字段标记为错误，并阻止相关字段入库

- [ ] **AC-016**: 资料不完整不得参与推荐
  - **Given** 某原纸已建立基础档案，但缺少纸价、纸类、用途/适用瓦型或强度指标等推荐所需资料
  - **When** 后续生成配纸方案
  - **Then** 该原纸不参与正式推荐，并在资料库中显示为资料不完整

- [ ] **AC-017**: 修改重要字段未填写原因
  - **Given** 用户修改纸价、克重、用途、适用瓦型、耐破指数、横向环压指数或启用状态
  - **When** 用户未填写修改原因并尝试保存
  - **Then** 系统阻止保存，并提示需要填写修改原因

- [ ] **AC-018**: 停用原纸
  - **Given** 某原纸当前处于启用状态
  - **When** 用户填写原因并停用该原纸
  - **Then** 系统将其标记为停用，并确保该原纸不再参与新方案推荐

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-019**: 原纸代码全局唯一 ← BR-001
  - **Given** 任意原纸导入或手工保存场景
  - **When** 用户提交原纸代码
  - **Then** 系统必须确保原纸代码在箱板纸和瓦纸范围内全局唯一

- [ ] **AC-020**: 原纸编码不能作为唯一标识 ← BR-002
  - **Given** 多张原纸拥有相同原纸编码
  - **When** 系统执行自动关联
  - **Then** 系统不得仅凭原纸编码唯一确定原纸，必须结合其他信息或进入待确认

- [ ] **AC-021**: 不静默猜测关联 ← BR-003, BR-005
  - **Given** 自动关联结果存在多个可能候选
  - **When** 用户查看预览
  - **Then** 系统必须展示待确认清单，而不是直接入库为某个候选

- [ ] **AC-022**: 自动关联优先级 ← BR-004
  - **Given** 导入记录同时具备多个可用于关联的字段
  - **When** 系统执行自动关联
  - **Then** 系统按原纸代码精确匹配、原纸编码辅助匹配、供应商简称 + 原纸名称 + 克重组合匹配的顺序处理

- [ ] **AC-023**: 变更历史可查看 ← BR-008, BR-009
  - **Given** 某原纸经历过导入更新或手工修改
  - **When** 用户打开该原纸的修改历史
  - **Then** 用户可以看到修改字段、旧值、新值、修改人、修改时间和修改原因

- [ ] **AC-024**: 历史方案不被主数据更新覆盖 ← BR-010
  - **Given** 后续已有历史方案保存了某次计算时的原纸快照
  - **When** 用户更新该原纸的当前纸价或强度指标
  - **Then** 历史方案仍展示保存时的快照值，不被当前资料覆盖

- [ ] **AC-025**: 不处理历史订单数据 ← BR-011
  - **Given** 本功能完成后
  - **When** 检查功能交付范围
  - **Then** 系统不包含近三年订单数据导入、历史订单清洗或历史习惯分析能力

## 变更日志 (Change Log)

### CR-001: 主数据多来源导入页面闭环收口 (2026-06-30)

**变更类型**: 扩展

**变更原因**: 主数据底层已具备纸价表和物理指标/标准表解析、关联与确认入库能力，但页面和服务端动作仍主要围绕原纸代码表，用户层面的多表导入闭环不完整。

**变更内容**:
- 页面导入来源选择扩展为原纸代码表、纸价表、物理指标/标准表。
- `previewMasterDataImport` 按 `sourceType` 分发解析和预览逻辑。
- 预览区域展示纸价表和指标表的更新、待确认、失败、标准规则等结果。
- 页面接入待确认关联处理，确认后可继续确认入库。
