# 方案 PDF 导出 — 功能需求说明书

## 1. 背景与价值

**为什么做**：配纸工具用于客户询价、报价和打样前的单次配纸决策。销售业务员需要把已确认的方案快速整理成可分享的方案表，工艺人员需要保留带成本、强度校核和推荐依据的完整报告，方便内部复盘和后续追溯。如果导出内容不区分内部和客户沟通场景，容易泄露内部成本；如果允许导出未保存或未校核方案，又会造成报价依据不可靠。

**做成什么样**：用户只能对已确认保存、达标且可生产的最终方案导出 PDF。导出分为完整配纸报告和精简方案表两种：完整报告默认内部使用，保留成本和原始三套推荐对比；精简方案表用于客户沟通，只展示最终确认方案、方案配置、强度、达标/可生产状态和推荐结论，不展示内部成本。每次导出记录导出类型和导出时间，并在历史方案中可查看。

**关联**：`specs/开发路线图.md` Milestone 2 / Phase 2.3 / 方案 PDF 导出；对应业务能力为完整配纸报告 PDF 和精简方案表 PDF。

## 2. 范围

### 本次做

- 在当前配纸结果页支持对已确认保存的最终方案导出 PDF。
- 在历史方案页支持打开已保存方案后导出 PDF。
- 支持完整配纸报告 PDF，默认用于内部沟通，展示成本信息。
- 支持精简方案表 PDF，默认用于客户沟通，不展示内部成本信息。
- 完整配纸报告展示输入参数、原始三套推荐对比、最终确认方案、强度校核、成本和推荐结论。
- 精简方案表展示最终确认方案、方案配置、强度、达标状态、可生产状态和推荐结论。
- 每次导出在历史方案中记录导出类型和导出时间。
- PDF 抬头和文件名按默认规则生成。
- 中文表格和长文本在 PDF 中应完整可读，不截断关键字段。

### 本次不做

- 不导出未确认保存的当前方案。
- 不导出未达标或不可生产的方案。
- 不引入客户信息、客户抬头或客户关联。
- 不做批量导出。
- 不做 PDF 模板自定义。
- 不做导出后的文件归档或外部发送。
- 不做原纸数据、公式/参数或历史方案的 Excel/JSON 备份导出。

## 4. 需求详述

### 4.1 核心流程

1. 用户填写纸箱参数、产品信息、堆码要求和生产数量后生成推荐方案。
2. 用户选择一套达标且可生产的方案作为最终方案。
3. 如用户调整过方案，必须先完成重新校核。
4. 用户点击“确认保存”，方案保存成功后才允许导出。
5. 用户可在当前结果页选择导出完整配纸报告或精简方案表。
6. 用户也可进入历史方案页，打开已保存方案并选择导出完整配纸报告或精简方案表。
7. PDF 导出成功后，历史方案中新增一条导出记录，记录导出类型和导出时间。

### 4.2 交互规则

- 当前方案未确认保存时，不提供 PDF 导出。
- 当前方案处于“待重新校核”状态时，不允许确认保存，也不允许导出。
- 最终方案未达标或不可生产时，不允许确认保存，因此不提供 PDF 导出。
- 保存成功后的当前结果页，应提供完整报告和精简方案表两种导出入口。
- 历史方案详情中，应提供完整报告和精简方案表两种导出入口。
- 完整报告默认内部使用，应清楚展示成本、强度校核和推荐结论。
- 精简方案表默认客户沟通使用，应避免展示内部成本信息。
- PDF 生成失败时，应提示导出失败，并保留当前页面和历史方案内容不变。
- PDF 中中文表格、方案名称、选型理由和状态说明应完整可读。
- 历史方案详情应按时间展示导出记录。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 只能导出已确认保存的最终方案。 |
| BR-002 | 未达标或不可生产的方案不能确认保存，也不能导出 PDF。 |
| BR-003 | 完整配纸报告默认用于内部沟通，允许展示成本信息。 |
| BR-004 | 精简方案表默认用于客户沟通，不得展示内部成本信息。 |
| BR-005 | 完整配纸报告必须展示输入参数、原始三套推荐对比、最终确认方案、强度校核、成本和推荐结论。 |
| BR-006 | 精简方案表只展示最终确认方案、方案配置、强度、达标状态、可生产状态和推荐结论。 |
| BR-007 | 每次成功导出都必须在历史方案中记录导出类型和导出时间。 |
| BR-008 | PDF 文件抬头和文件名使用默认规则，不引入客户信息。 |
| BR-009 | PDF 中文内容和表格关键字段必须完整可读，不得因截断影响理解。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 当前结果页提供导出入口
  - **Given** 用户已确认保存一套达标且可生产的最终方案
  - **When** 用户在当前结果页查看该方案
  - **Then** 页面提供“完整报告 PDF”和“精简方案表 PDF”导出入口

- [ ] **AC-002**: 历史方案页提供导出入口
  - **Given** 用户在历史方案页打开一条已保存方案
  - **When** 用户选择导出 PDF
  - **Then** 页面提供“完整报告 PDF”和“精简方案表 PDF”两种导出类型

- [ ] **AC-003**: 导出完整配纸报告
  - **Given** 用户选择导出完整报告
  - **When** PDF 生成完成
  - **Then** PDF 包含输入参数、原始三套推荐对比、最终确认方案、强度校核、成本和推荐结论

- [ ] **AC-004**: 导出精简方案表
  - **Given** 用户选择导出精简方案表
  - **When** PDF 生成完成
  - **Then** PDF 仅包含最终确认方案、方案配置、强度、达标状态、可生产状态和推荐结论，不展示内部成本

- [ ] **AC-005**: 导出成功后记录导出信息
  - **Given** PDF 导出成功
  - **When** 用户查看历史方案详情
  - **Then** 该方案显示对应导出类型和导出时间

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-006**: 未保存方案不允许导出
  - **Given** 当前方案尚未确认保存
  - **When** 用户尝试导出 PDF
  - **Then** 系统不允许导出，并提示“请先确认保存方案后再导出”

- [ ] **AC-007**: 待重新校核方案不允许继续
  - **Given** 方案处于待重新校核状态
  - **When** 用户尝试确认保存或导出
  - **Then** 系统不允许继续，并提示先重新校核

- [ ] **AC-008**: 未达标或不可生产方案无法进入导出
  - **Given** 最终方案未达标或不可生产
  - **When** 用户尝试确认保存
  - **Then** 系统不允许保存，因此不提供 PDF 导出

- [ ] **AC-009**: PDF 生成失败
  - **Given** PDF 生成失败
  - **When** 用户查看结果
  - **Then** 系统提示导出失败，并保留当前页面和历史方案内容不变

- [ ] **AC-010**: 中文内容完整可读
  - **Given** PDF 中包含较长中文内容或表格字段
  - **When** PDF 生成完成
  - **Then** 表格文字不截断，关键字段可完整阅读

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-011**: 只能导出已确认保存方案
  - **Given** 任意导出场景
  - **When** 用户导出 PDF
  - **Then** 只能导出已确认保存的最终方案

- [ ] **AC-012**: 完整报告允许展示成本
  - **Given** 用户导出完整报告
  - **When** 查看报告内容
  - **Then** 成本相关信息允许展示，默认用于内部沟通

- [ ] **AC-013**: 精简方案表不展示内部成本
  - **Given** 用户导出精简方案表
  - **When** 查看方案表内容
  - **Then** 不展示单箱含税成本、各层单价、用纸总价、加工费用、税金等内部成本信息

- [ ] **AC-014**: PDF 抬头和文件名使用默认规则
  - **Given** PDF 文件生成
  - **When** 用户查看文件抬头和文件名
  - **Then** 完整报告抬头为“配纸方案报告”，精简方案表抬头为“配纸方案表”，文件名包含“配纸方案”、保存时间和导出类型

- [ ] **AC-015**: 多次导出记录可追溯
  - **Given** 历史方案已有多次导出
  - **When** 用户查看导出记录
  - **Then** 每次导出都按时间展示导出类型和导出时间
