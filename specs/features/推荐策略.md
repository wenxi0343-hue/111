# 推荐策略 — 功能需求说明书

## 1. 背景与价值

**为什么做**：推荐策略是配纸工具从“能算”走向“能帮用户决策”的关键。工艺人员和销售业务员需要在单次配纸后快速看到经济型、安全型、均衡型三套方案，并清楚知道哪些方案达标、哪些方案不达标、为什么不足三套。

**做成什么样**：用户输入完整纸箱参数并生成方案后，系统基于已完成的面积、强度、成本和设备限制结果，生成经济型、安全型、均衡型三个方案位置。系统优先展示达标且可生产的不同配纸组合；若不同组合不足三套，允许重复展示同一组合并说明原因；若某个方案位置没有可用结果，保留位置并展示可用方案不足的具体原因。

**关联**：`specs/开发路线图.md` Milestone 1 / Phase 1.4 / 候选组合生成与硬规则过滤、三套推荐方案；对应业务能力为推荐策略。

## 2. 范围

### 本次做

- 生成经济型、安全型、均衡型三个方案位置。
- 按硬规则优先判断候选是否达标、是否可生产。
- 经济型优先选择含税成本最低的达标可生产方案。
- 安全型优先选择抗压富余率最高且不超过 200% 的达标可生产方案。
- 均衡型按成本和安全综合表现选择达标可生产方案。
- 三类方案优先展示不同配纸组合。
- 不同组合不足三套时，实在找不到不同组合才允许重复展示同一组合，并说明重复原因。
- 某个方案位置没有可用结果时，保留位置并展示可用方案不足的具体原因。
- 所有候选都不达标或不可生产时，仍展示参考方案，并明确标记不达标或不可生产原因。
- 候选方案不达标时，展示具体不达标项，例如耐破不足、边压不足或空箱抗压不足。
- 候选方案不可生产时，展示具体不可生产原因，例如超过设备最大宽度。

### 本次不做

- 不做历史习惯评分。
- 不按客户偏好影响推荐排序。
- 不做方案版本对比。
- 不让 AI 参与推荐排序。
- 不让 AI 改变成本、强度、达标状态或推荐结果。
- 不做批量配纸。
- 不新增 PRD 之外的强度、成本或设备判断口径。

## 4. 需求详述

### 4.1 核心流程

1. 用户在配纸输入页面填写完整纸箱参数、产品信息、堆码要求和生产数量。
2. 用户点击生成方案。
3. 系统基于候选计算结果，先识别达标且可生产的候选组合。
4. 存在达标且可生产候选时，系统按经济型、安全型、均衡型分别选择方案。
5. 系统优先为三个方案位置选择不同配纸组合。
6. 如果不同组合不足三套，系统允许重复展示同一组合，并说明该组合同时满足哪些策略的最优结果。
7. 如果某个方案位置没有可用结果，系统保留该位置，并显示可用方案不足的具体原因。
8. 如果所有候选都不达标或不可生产，系统展示参考方案，并提示当前没有达标可生产方案。
9. 用户查看方案对比结果，看到成本、耐破、边压、空箱抗压、是否达标、是否可生产和选型理由。

### 4.2 交互规则

- 页面固定展示经济型、安全型、均衡型三个方案位置。
- 正式推荐应优先来自达标且可生产的候选。
- 三个方案位置优先展示不同配纸组合。
- 如果同一组合同时是多个策略下的最优结果，且没有足够不同组合可选，可在多个方案位置重复展示。
- 重复展示同一组合时，必须说明它同时符合哪些策略。
- 某个方案位置没有可用结果时，不隐藏该位置，应显示可用方案不足原因。
- 所有候选都不达标或不可生产时，顶部提示“当前没有达标可生产方案，以下仅供调整参考”。
- 未达标方案应显示具体不足项。
- 不可生产方案应显示具体设备限制原因。
- 原纸、纸厂或基础参数不足以生成方案时，不展示推荐结果，应提示用户先维护缺失数据。

### 4.3 业务规则

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 展示三个方案位置
  - **Given** 用户已填写完整纸箱参数、产品信息、堆码要求和生产数量
  - **When** 用户生成方案
  - **Then** 页面展示经济型、安全型、均衡型三个方案位置

- [ ] **AC-002**: 三类方案按策略生成
  - **Given** 存在多套达标且可生产的候选方案
  - **When** 系统生成推荐结果
  - **Then** 经济型展示含税成本最低的方案，安全型展示抗压富余率最高且不超过 200% 的方案，均衡型展示成本和安全综合表现最优的方案

- [ ] **AC-003**: 三套不同方案正常展示
  - **Given** 三类策略各自存在不同的最优组合
  - **When** 页面展示推荐结果
  - **Then** 三个方案位置展示三套不同配纸组合，并显示成本、耐破、边压、空箱抗压、是否达标、是否可生产和选型理由

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-004**: 可用不同组合不足三套
  - **Given** 达标且可生产的不同候选组合不足三套
  - **When** 页面展示推荐结果
  - **Then** 页面保留经济型、安全型、均衡型三个位置，并在缺失位置显示可用方案不足的具体原因

- [ ] **AC-005**: 同一组合可重复展示
  - **Given** 同一套配纸组合同时满足多个策略的最优结果
  - **When** 不存在足够的不同组合可展示
  - **Then** 页面允许重复展示该组合，并说明“该组合同时也是某策略下最优”

- [ ] **AC-006**: 所有候选都不达标或不可生产
  - **Given** 所有候选方案都不达标或不可生产
  - **When** 页面展示推荐结果
  - **Then** 顶部提示“当前没有达标可生产方案，以下仅供调整参考”，并在每个参考方案上显示未达标或不可生产原因

- [ ] **AC-007**: 强度不足原因可见
  - **Given** 某个候选方案强度不足
  - **When** 页面展示该方案
  - **Then** 页面明确显示具体不足项，例如耐破不足、边压不足或空箱抗压不足

- [ ] **AC-008**: 设备限制原因可见
  - **Given** 某个候选方案超过设备限制
  - **When** 页面展示该方案
  - **Then** 页面明确标记为“不可生产”，并显示超过设备最大宽度等具体原因

- [ ] **AC-009**: 基础数据不足时阻止生成
  - **Given** 原纸、纸厂或基础参数不足以生成方案
  - **When** 用户尝试生成方案
  - **Then** 页面不生成推荐方案，并提示用户先维护缺失数据

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-010**: 未达标或不可生产不得标记为达标推荐
  - **Given** 任意候选方案未达标或不可生产
  - **When** 系统生成正式推荐
  - **Then** 该方案不得被标记为达标推荐

- [ ] **AC-011**: 安全型排除过高冗余方案
  - **Given** 安全型方案参与排序
  - **When** 某候选方案抗压富余率超过 200%
  - **Then** 该方案不作为安全型正式推荐；若因此无可用安全型方案，页面显示原因

- [ ] **AC-012**: 均衡型默认权重
  - **Given** 均衡型方案参与排序，且用户未调整成本和安全权重
  - **When** 系统判断均衡型推荐结果
  - **Then** 默认按成本 50%、安全 50% 进行综合判断

- [ ] **AC-013**: 历史习惯和 AI 不参与本次推荐
  - **Given** 本次推荐策略生成完成
  - **When** 页面展示结果
  - **Then** 不使用历史习惯影响排序，也不让 AI 改变成本、强度、达标状态或推荐结果
