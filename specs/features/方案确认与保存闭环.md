# 方案确认与保存闭环 — 功能需求说明书

## 1. 背景与价值

**为什么做**：推荐策略生成三套方案后，用户仍需要基于实际生产判断选择最终方案。工艺人员可能调整瓦型、层数、纸厂或克重后重新校核，销售业务员也需要把确认过的方案留作报价和后续沟通依据。如果没有明确的确认、重新校核和保存规则，历史方案会混入试算过程，后续追溯成本、强度和参数口径时不可靠。

**做成什么样**：用户生成经济型、安全型、均衡型三套推荐方案后，可选择一套作为最终方案，也可手动调整后重新校核；只有点击“确认保存”的最终方案才进入历史记录。历史记录保存原始三套推荐结果和最终确认方案，并保留价格快照、参数版本、是否手动调整和保存时间。

**关联**：`specs/开发路线图.md` Milestone 1 / Phase 1.4 / 方案确认与保存闭环；对应业务能力为方案调整、重新计算、历史方案保存和价格/参数快照。

---

## 2. 范围

### 本次做

- 从经济型、安全型、均衡型三套推荐方案中选择一套作为最终方案。
- 支持用户调整瓦型、纸箱层数、纸厂、面纸、里纸、芯纸和瓦纸克重。
- 用户调整后显示“待重新校核”状态。
- 用户点击“重新校核”后，重新生成强度、成本、是否达标和是否可生产状态。
- 禁止用户手动编辑计算值、是否达标、是否可生产和选型理由。
- 用户点击“确认保存”后，才写入历史记录。
- 历史记录保存输入参数、生产数量、原始三套推荐结果、最终确认方案、原纸价格快照、基础参数版本、是否手动调整、导出记录和保存时间。
- 用户调整后的最终方案未达标或不可生产时允许保存，但必须醒目标记状态并提示不建议生产。
- 历史记录自动保留最新 50 条，最旧记录自动移出历史列表。

### 本次不做

- 不做方案版本对比。
- 不支持一次确认保存多套最终方案。
- 不做历史习惯评分。
- 不做方案 PDF 导出。
- 不做复杂审批流程。
- 不做客户信息关联。
- 不新增 PRD 之外的强度、成本或设备判断口径。

## 4. 需求详述

### 4.1 核心流程

1. 用户填写纸箱参数、产品信息、堆码要求和生产数量后生成推荐方案。
2. 页面展示经济型、安全型、均衡型三套原始推荐结果。
3. 用户选择其中一套作为当前最终方案。
4. 用户可直接确认保存，也可调整瓦型、纸箱层数、纸厂和各层克重。
5. 用户调整方案后，页面显示“待重新校核”。
6. 用户点击“重新校核”后，页面更新耐破、边压、空箱抗压、成本、是否达标和是否可生产状态。
7. 用户点击“确认保存”后，历史记录保存原始三套推荐结果和最终确认方案。
8. 历史列表自动保留最新 50 条确认保存记录。

### 4.2 交互规则

- 三套推荐方案生成后，用户必须明确选择一套作为当前最终方案。
- 未调整的推荐方案可直接确认保存。
- 用户修改瓦型、层数、纸厂或任一层克重后，当前最终方案立即变为“待重新校核”。
- “待重新校核”的方案不得保存。
- 用户点击“重新校核”后，页面才更新计算值和状态。
- 调整后的最终方案未达标或不可生产时，页面仍允许确认保存，但必须醒目标记“未达标”或“不可生产”，并提示“不建议生产”。
- 保存成功后，历史记录应能看出该方案是否经过用户手动调整。
- 单纯生成推荐方案不写入历史记录。
- 历史列表超过 50 条时，不弹确认，自动移出最旧记录。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 只有用户点击“确认保存”的方案才进入历史记录。 |
| BR-002 | 每次确认保存只能保存一套最终确认方案。 |
| BR-003 | 历史记录必须随同保存原始三套推荐结果作为对比记录。 |
| BR-004 | 用户调整瓦型、层数、纸厂或克重后，必须重新校核才能保存。 |
| BR-005 | 计算值、是否达标、是否可生产和选型理由不可手动编辑。 |
| BR-006 | 用户调整后的最终方案未达标或不可生产时允许保存，但必须显示风险状态和不建议生产提示。 |
| BR-007 | 历史记录最多保留最近 50 条，超过后自动移出最旧记录。 |
| BR-008 | 用户修改过瓦型、层数、纸厂或克重并完成保存后，历史记录必须标记“用户已手动调整”。 |
| BR-009 | 历史记录至少保存输入参数、生产数量、原纸价格快照、基础参数版本、推荐方案结果、最终确认方案、是否手动调整、导出记录和保存时间。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 选择最终方案
  - **Given** 用户已生成经济型、安全型、均衡型三套推荐方案
  - **When** 用户选择其中一套方案
  - **Then** 页面将该方案标记为当前最终方案

- [ ] **AC-002**: 未调整方案直接保存
  - **Given** 用户已选择一套未调整的推荐方案作为当前最终方案
  - **When** 用户点击“确认保存”
  - **Then** 系统保存输入参数、生产数量、原始三套推荐结果、最终确认方案、原纸价格快照、基础参数版本和保存时间

- [ ] **AC-003**: 调整后重新校核
  - **Given** 用户已选择一套推荐方案作为当前最终方案
  - **When** 用户调整瓦型、层数、纸厂或任一层克重后点击“重新校核”
  - **Then** 页面更新耐破、边压、空箱抗压、成本、是否达标和是否可生产状态

- [ ] **AC-004**: 保存调整后方案
  - **Given** 用户已调整方案并完成重新校核
  - **When** 用户点击“确认保存”
  - **Then** 历史记录包含原始三套推荐结果和用户最终确认的调整后方案，并标记“用户已手动调整”

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-005**: 待重新校核时禁止保存
  - **Given** 用户调整方案后尚未重新校核
  - **When** 用户点击“确认保存”
  - **Then** 系统阻止保存，并提示“请先重新校核后再保存”

- [ ] **AC-006**: 未达标或不可生产方案允许保存但标记风险
  - **Given** 用户最终确认的方案未达标或不可生产
  - **When** 用户点击“确认保存”
  - **Then** 系统允许保存，但醒目标记“未达标”或“不可生产”，并提示“不建议生产”

- [ ] **AC-007**: 历史记录超过 50 条
  - **Given** 历史记录已达到 50 条
  - **When** 新方案保存成功
  - **Then** 历史列表保留最新 50 条记录，最旧记录自动移出历史列表

- [ ] **AC-008**: 调整后状态不可误认为可保存
  - **Given** 用户手动调整了方案
  - **When** 尚未完成重新校核
  - **Then** 页面显示“待重新校核”，且不得展示该方案为可保存状态

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-009**: 计算结果不可手动编辑 ← BR-005
  - **Given** 任意推荐方案或调整后方案
  - **When** 用户查看或编辑方案
  - **Then** 计算值、是否达标、是否可生产和选型理由不可手动编辑

- [ ] **AC-010**: 生成推荐不自动保存 ← BR-001
  - **Given** 用户完成一次推荐方案生成
  - **When** 用户未点击“确认保存”
  - **Then** 该次推荐结果不进入历史记录

- [ ] **AC-011**: 一次只保存一套最终方案 ← BR-002, BR-003
  - **Given** 用户准备保存方案
  - **When** 用户点击“确认保存”
  - **Then** 系统一次只保存一套最终确认方案，原始三套推荐结果仅作为对比记录随同保存

- [ ] **AC-012**: 手动调整状态可追溯 ← BR-008
  - **Given** 用户修改过瓦型、层数、纸厂或克重并保存最终方案
  - **When** 用户查看历史记录
  - **Then** 历史记录显示“用户已手动调整”

- [ ] **AC-013**: 历史记录字段完整 ← BR-009
  - **Given** 用户确认保存最终方案
  - **When** 历史记录生成
  - **Then** 历史记录包含输入参数、生产数量、原纸价格快照、基础参数版本、推荐方案结果、最终确认方案、是否手动调整、导出记录和保存时间

## 附录：已确认口径

| 项目 | 口径 |
|------|------|
| 保存时机 | 用户点击“确认保存”后才写入历史记录，单纯生成推荐不保存。 |
| 保存内容 | 保存原始三套推荐结果和用户最终确认的一套方案。 |
