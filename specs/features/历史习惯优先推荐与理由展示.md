# 历史习惯优先推荐与理由展示 — 功能需求说明书

## 1. 背景与价值

**为什么做**：纸箱自动配纸工具已经具备确定性计算、推荐策略和历史订单习惯提取能力。用户希望新方案不是凭空组合出来的，而是先总结公司以往真实订单中的配纸习惯，再把这些习惯用于推荐算法，让系统生成的方案更符合公司长期形成的工艺经验。

**做成什么样**：系统基于已清洗、可统计的历史订单形成配纸习惯摘要。用户生成新方案时，系统根据产品名称或类别、尺寸区间、重量区间匹配历史习惯，优先使用常用层数、瓦型、纸厂和克重组合生成候选方案；再重新校核当前强度、成本和设备限制；最终仍输出经济型、安全型、均衡型三类方案，并展示历史匹配等级和理由。

**关联**：`specs/开发路线图.md` Milestone 2 / Phase 2.2 / 历史习惯评分与理由展示；前置功能为 `specs/features/历史订单建库与习惯提取.md`，本功能把已形成的历史习惯摘要用于推荐策略。

## 2. 范围

### 本次做

- 查看历史配纸习惯摘要。
- 推荐方案时默认使用已形成的历史配纸习惯，不要求用户每次人工确认。
- 按产品名称或类别、尺寸区间、重量区间匹配历史习惯。
- 优先使用历史常用层数、瓦型、纸厂和克重组合生成候选方案。
- 对历史习惯候选方案重新校核当前强度、成本和设备限制。
- 保留经济型、安全型、均衡型三类方案。
- 展示历史匹配等级：高匹配、中匹配、低匹配、暂无足够历史参考。
- 展示历史理由，说明方案参考了哪些公司历史习惯。
- 历史常用组合不达标、不可生产或无法匹配当前可用原纸时，推荐达标的相近方案并说明原因。
- 相似历史订单不足时，回退到现有推荐逻辑，并显示“暂无足够历史参考”。

### 本次不做

- 不要求用户每次推荐前人工确认历史习惯。
- 不做客户信息关联。
- 不做客户偏好推荐。
- 不做成本趋势分析。
- 不做批量配纸。
- 不修改面积、强度、成本、设备限制等公式口径。
- 不把历史价格、历史成本或历史公式口径作为当前成本结论。
- 不让历史习惯覆盖强度、成本和设备限制硬规则。
- 不展示裸分数，只展示匹配等级和理由。

## 4. 需求详述

### 4.1 核心流程

1. 系统从已清洗、可统计的历史订单中形成历史配纸习惯摘要。
2. 用户可查看历史配纸习惯摘要，了解不同产品、尺寸和重量区间下的常用层数、瓦型、纸厂和克重组合。
3. 用户在配纸输入页面填写纸箱参数、产品信息、堆码要求和生产数量。
4. 用户生成方案。
5. 系统根据产品名称或类别、尺寸区间、重量区间匹配历史配纸习惯。
6. 如果存在足够相似历史订单，系统优先使用匹配到的常用层数、瓦型、纸厂和克重组合生成候选方案。
7. 系统对候选方案重新校核当前强度、成本和设备限制。
8. 历史常用组合达标且可生产时，可作为经济型、安全型、均衡型方案的优先来源。
9. 历史常用组合不达标、不可生产或无法匹配当前可用原纸时，系统不直接推荐该组合，改为推荐达标的相近方案，并说明原因。
10. 相似历史订单不足时，系统回退到现有推荐逻辑，并显示“暂无足够历史参考”。
11. 页面展示经济型、安全型、均衡型三类方案，同时展示历史匹配等级和理由。

### 4.2 交互规则

- 历史配纸习惯摘要可查看，但不要求用户每次生成方案前人工确认。
- 生成方案时默认使用已形成的历史习惯摘要。
- 页面展示历史匹配等级，不展示裸分数。
- 历史匹配等级包括高匹配、中匹配、低匹配、暂无足够历史参考。
- 历史理由必须使用业务语言，说明参考了哪些历史习惯，例如相似产品、相似尺寸、相似重量区间下常用的层数、瓦型、纸厂或克重组合。
- 如果历史常用组合没有直接采用，页面必须说明原因。
- 历史样本不足时，不显示高匹配、中匹配或低匹配，只显示“暂无足够历史参考”。
- 推荐结果仍固定展示经济型、安全型、均衡型三个方案位置。
- 未达标或不可生产方案必须按现有规则展示状态和原因，不能因为符合历史习惯而显示为达标。

### 4.3 业务规则

| 编号 | 规则 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 查看历史习惯摘要
  - **Given** 系统已从可统计历史订单中形成历史配纸习惯摘要
  - **When** 用户查看历史习惯摘要
  - **Then** 页面按产品名称或类别、尺寸区间、重量区间展示常用层数、瓦型、纸厂和克重组合

- [ ] **AC-002**: 常用组合按频率展示
  - **Given** 同一历史习惯维度下存在多种配纸组合
  - **When** 页面展示历史习惯摘要
  - **Then** 常用层数、瓦型、纸厂和克重组合按出现频率从高到低展示

- [ ] **AC-003**: 历史习惯默认参与推荐
  - **Given** 系统已形成可用的历史配纸习惯摘要
  - **When** 用户生成新配纸方案
  - **Then** 系统不要求用户每次人工确认历史习惯，默认使用匹配到的历史习惯生成候选方案

- [ ] **AC-004**: 优先使用匹配历史习惯生成候选
  - **Given** 当前纸箱参数匹配到足够相似的历史习惯
  - **When** 系统生成候选方案
  - **Then** 系统优先使用历史常用层数、瓦型、纸厂和克重组合生成候选方案

- [ ] **AC-005**: 保留三类方案
  - **Given** 历史习惯候选方案存在达标且可生产的结果
  - **When** 系统输出推荐结果
  - **Then** 页面仍展示经济型、安全型、均衡型三个方案位置

- [ ] **AC-006**: 三类方案定位保持清晰
  - **Given** 页面展示经济型、安全型、均衡型方案
  - **When** 用户查看方案定位
  - **Then** 经济型偏低成本，安全型偏高强度富余，均衡型兼顾历史习惯、成本和安全

- [ ] **AC-007**: 展示历史匹配等级
  - **Given** 某方案参考了历史习惯
  - **When** 用户查看方案结果
  - **Then** 页面展示高匹配、中匹配、低匹配或暂无足够历史参考

- [ ] **AC-008**: 展示历史理由
  - **Given** 某方案展示历史匹配等级
  - **When** 用户查看方案理由
  - **Then** 页面说明该方案参考了哪些历史习惯，例如相似产品、相似尺寸或相似重量区间下的常用层数、瓦型、纸厂或克重组合

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-009**: 历史常用组合不达标时推荐相近方案
  - **Given** 匹配到的历史常用组合不满足当前强度要求
  - **When** 系统生成推荐方案
  - **Then** 页面不把该历史常用组合作为达标推荐，并改为展示达标的相近方案和未直接采用的原因

- [ ] **AC-010**: 历史常用组合不可生产时推荐相近方案
  - **Given** 匹配到的历史常用组合不满足当前设备限制
  - **When** 系统生成推荐方案
  - **Then** 页面不把该历史常用组合作为可生产推荐，并改为展示可生产的相近方案和未直接采用的原因

- [ ] **AC-011**: 历史常用组合无法匹配当前可用原纸
  - **Given** 匹配到的历史常用纸厂或克重组合在当前原纸资料中不可用
  - **When** 系统生成推荐方案
  - **Then** 页面改用当前可用原纸中的相近方案，并说明历史常用组合当前不可用

- [ ] **AC-012**: 相似历史订单不足
  - **Given** 与当前纸箱参数相似的可统计历史订单少于 5 条
  - **When** 系统生成推荐方案
  - **Then** 页面显示“暂无足够历史参考”，并回退到现有推荐逻辑

- [ ] **AC-013**: 没有达标可生产方案
  - **Given** 历史习惯候选和现有推荐候选都没有达标且可生产方案
  - **When** 系统展示推荐结果
  - **Then** 页面按现有规则展示未达标或不可生产状态，不因历史习惯改变状态

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-014**: 历史习惯不得覆盖硬规则
  - **Given** 任意历史习惯数据
  - **When** 系统生成推荐方案
  - **Then** 历史习惯不得覆盖强度、成本和设备限制硬规则

- [ ] **AC-015**: 历史常用组合必须重新校核
  - **Given** 某历史常用组合被用于生成候选方案
  - **When** 系统输出推荐结果
  - **Then** 页面展示的是按当前输入重新校核后的成本、强度、达标状态和可生产状态

- [ ] **AC-016**: 历史成本不作为当前结论
  - **Given** 历史订单中包含价格、成本或历史公式口径
  - **When** 系统生成当前推荐方案
  - **Then** 页面不把历史价格、历史成本或历史公式口径作为当前成本结论

- [ ] **AC-017**: 历史理由必须来自摘要
  - **Given** 页面展示历史匹配理由
  - **When** 用户查看理由内容
  - **Then** 理由必须来自历史习惯摘要，不得凭空生成没有统计依据的结论

- [ ] **AC-018**: 只展示等级不展示裸分数
  - **Given** 页面展示历史匹配结果
  - **When** 用户查看方案详情
  - **Then** 页面只展示高匹配、中匹配、低匹配或暂无足够历史参考，不展示裸分数

- [ ] **AC-019**: 不扩大到客户偏好
  - **Given** 本功能完成后
  - **When** 检查功能范围
  - **Then** 不包含客户信息关联、客户偏好推荐、成本趋势分析或批量配纸
