## 问题与决策

### 直接 Node 运行脚本不识别路径别名

**情况**：`pnpm db:check` 直接通过 Node 执行脚本时，无法解析 TypeScript 路径别名 `@/`。

**处理**：数据库运行时入口改用相对 `.ts` 扩展导入，保留测试和应用代码中的别名能力。

**影响**：后续新增直接由 Node 执行的脚本时，应避免依赖 `@/` 路径别名，或显式配置运行时解析器。

### 真实 PostgreSQL 未配置

**情况**：当前环境未提供可用 PostgreSQL 连接。

**处理**：已验证 `pnpm db:generate` 可执行且无重复迁移；已验证 `db:check` 和 `db:seed` 在无配置时返回脱敏失败提示。

**影响**：部署或本地数据库准备好后，还需要执行一次 `pnpm db:migrate` 和 `pnpm db:seed` 的真实写库验收。
