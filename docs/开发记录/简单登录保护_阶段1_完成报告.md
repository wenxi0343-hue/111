## 问题与决策

### 使用内置 Node 运行测试

**情况**：当前终端 PATH 中没有系统 `node`，直接运行 `pnpm` 会提示找不到 Node。

**处理**：使用 Codex 工作区内置 Node 路径临时加入 PATH 后运行 `pnpm`。

**影响**：后续本地运行命令时，如果用户终端也没有 Node，需要安装 Node 或使用 Codex 内置运行时。

### 会话模块保持纯函数

**情况**：Task-02 只要求会话载荷、签名、验证和 cookie 配置。

**处理**：本阶段没有直接读写 Next.js `cookies()`，而是先提供纯函数，方便 Server Actions 和页面保护在后续任务中复用。

**影响**：Task-03、Task-05、Task-06、Task-07 可以直接复用 `createSessionValue`、`verifySessionValue` 和 `getSessionCookieOptions`。
