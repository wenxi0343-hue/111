## 问题与决策

### 查询边界

**情况**：Task-04 已在确认导入后生成摘要，本阶段只需要读取和展示，不应重新扫描历史订单。  
**处理**：新增 `listHistoricalOrderHabitSummaries`，从摘要表读取结果，并保留维度筛选和数量限制。  
**影响**：页面展示不会改变确认导入事务，也不会触碰历史订单原始数据统计口径。

### 功能范围隔离

**情况**：需求明确历史习惯只能作为摘要展示，不能扩展为客户偏好、推荐排序或成本趋势。  
**处理**：在 README 中写明边界，并用范围回归测试扫描 schema、`calculations` 和 `recommendation` 目录。  
**影响**：后续若要把历史习惯接入推荐，只能在硬规则过滤之后另行设计，不能在本阶段隐式改变现有推荐结果。
