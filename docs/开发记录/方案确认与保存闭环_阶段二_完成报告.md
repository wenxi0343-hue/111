# 方案确认与保存闭环 — 阶段二完成报告

## 阶段范围

阶段二目标是让用户生成三套推荐后，可以选择其中一套作为最终方案并确认保存；仅生成推荐不会进入历史记录。

## 已完成内容

- 完成未调整最终方案保存闭环：保存输入快照、原始三套推荐、最终确认方案、价格快照、参数版本和导出记录。
- 页面支持在经济型、安全型、均衡型推荐中选择最终方案，并显示“当前最终方案”。
- 页面新增“确认保存”动作，只有用户点击确认后才调用保存。
- 保存成功后页面显示“保存成功”。
- 推荐结果中的计算值、达标状态、可生产状态和选型理由均保持只读展示。
- 保存失败时页面展示业务提示，不暴露堆栈或底层错误。
