## 2. 产品愿景

纸箱自动配纸工具希望把纸箱厂依赖人工经验、Excel 表格和口头判断的单次配纸决策，沉淀为一套可计算、可追溯、可复核的业务系统。

用户输入纸箱尺寸、内装物重量、堆码要求、生产数量和产品信息后，系统基于公司已确认的面积、强度、成本和设备限制口径，自动生成经济型、安全型、均衡型配纸方案，并清楚展示成本、耐破、边压、空箱抗压、达标状态、生产可行性和选型理由。

## 3. 核心价值

| 价值 | 说明 |
|------|------|
| 降低配纸决策成本 | 让销售和工艺人员在询价、报价、打样前快速得到可比较的方案，减少重复手算和反复沟通。 |
| 提高计算可信度 | 面积、强度、成本、设备限制按统一公式执行，避免不同人员口径不一致。 |
| 兼顾成本与安全 | 经济型、安全型、均衡型三套方案分别覆盖低成本、高安全冗余和综合平衡决策。 |
| 保留业务追溯 | 历史方案保存输入、价格快照、参数版本和调整状态，便于后续复盘。 |
| 支持经验沉淀 | 后续通过历史订单清洗和习惯提取，把公司常用配纸规律变成推荐排序辅助依据。 |

## 4. 目标用户

| 用户角色 | 主要场景 | 核心诉求 |
|----------|----------|----------|
| 工艺人员 | 打样前配纸、强度校核、方案调整 | 方案强度达标、公式口径清楚、参数可追溯、调整后能重新校核。 |
| 销售业务员 | 客户询价、报价前方案准备、方案分享 | 快速生成可解释方案，看到单箱成本和达标状态，并导出适合沟通的报告。 |
| 经营或管理人员 | 成本复盘、历史方案查看、参数治理 | 了解常见产品配纸成本、追溯历史方案和基础参数口径。 |

## 5. 典型业务场景

1. 客户询价时，销售输入纸箱尺寸、内装物重量、堆码层数和生产数量，快速得到三套可比较方案。
2. 工艺人员在打样前查看方案的耐破、边压、空箱抗压和设备限制，确认是否达标、是否可生产。
3. 用户手动调整瓦型、层数、纸厂或克重后，系统重新计算成本和强度，并重新标记达标状态。
4. 用户确认方案后保存历史记录，后续可查看最近 50 条历史方案。
5. 用户导出完整配纸报告或精简方案表，用于内部沟通、报价辅助或客户确认。
6. 后续导入历史订单后，系统提取公司常用层数、瓦型、纸厂和克重组合，辅助推荐排序和理由展示。

## 6. 产品范围

### 6.1 MVP 核心闭环

MVP 聚焦“维护基础数据 -> 输入纸箱参数 -> 生成三套方案 -> 查看成本/强度/设备状态 -> 手动调整 -> 保存历史”的最小业务闭环。

| 范围 | 内容 |
|------|------|
| 基础数据维护 | 维护纸厂、箱板纸、瓦纸、设备参数、瓦楞系数、纸板厚度、加工费用系数和利用率分段。 |
| 纸箱输入校验 | 校验纸箱尺寸、内装物重量、堆码层数、生产数量和尺寸合理性。 |
| 确定性计算 | 计算三层、五层、七层面积，设备限制，耐破，边压，空箱抗压，原纸利用率和含税成本。 |
| 方案推荐 | 生成经济型、安全型、均衡型三套方案，先按硬规则过滤，再按策略排序。 |
| 方案调整 | 支持用户调整瓦型、层数、纸厂、克重等字段，并由系统重新校核。 |
| 历史保存 | 保存最近 50 条历史方案，包含输入、价格快照、参数版本、推荐结果和调整状态。 |

### 6.2 功能完善范围

| 能力 | 定位 |
|------|------|
| 原纸 Excel/CSV 导入 | 提高主数据建库效率，导入内容作为不可信输入处理。 |
| 方案 PDF 导出 | 支持完整配纸报告和精简方案表，便于内部或客户沟通。 |
| 历史订单建库与习惯提取 | 清洗三年订单，统计公司配纸习惯，作为后续推荐辅助依据。 |
| 历史习惯参与推荐 | 历史习惯只能影响排序和理由展示，不能覆盖强度、成本和设备硬规则。 |
| AI 选型理由 | AI 只根据已计算结果生成说明，失败时使用模板理由，不阻断方案生成。 |
| 导出备份 | 支持原纸、公式参数和历史方案导出，便于基础备份。 |

### 6.3 首版不包含

- 批量配纸。
- 多用户复杂权限。
- 供应商价格自动同步。
- 客户信息关联。
- 方案版本对比。
- 摇盖类型选择及专项校验。
- 戳穿强度、吸潮变形等其他物理风险指标。
- 三层、五层两片成箱面积公式。

## 8. 核心业务流程

1. 用户登录系统。
2. 用户维护或导入纸厂、箱板纸、瓦纸和基础参数。
3. 用户进入单次配纸页面，填写纸箱参数、产品信息、堆码要求和生产数量。
4. 系统校验输入字段和基础数据完整性。
5. 系统基于公司默认公式计算面积、强度、成本和设备限制。
6. 系统生成候选组合，并过滤数据不足、不可生产或不达标的方案。
7. 系统输出经济型、安全型、均衡型方案，并展示成本、强度、达标状态和推荐理由。
8. 用户可手动调整方案，系统重新计算并更新状态。
9. 用户确认并保存方案，系统保留历史快照。
10. 用户按需要导出完整报告、精简方案表或备份数据。

## 9. 关键业务规则

| 规则类别 | 规则摘要 |
|----------|----------|
| 面积公式 | 三层、五层、七层普箱面积按 PRD 第 8.2 固化，七层支持两片成箱；三层、五层超设备宽度直接标记不可生产。 |
| 设备限制 | 按 PRD 第 8.3 固化生产纸板机器、印刷开槽机和开槽尺寸限制。 |
| 强度公式 | 仅计算耐破、边压、空箱抗压，按 PRD 第 8.4-8.7 固化。 |
| 成本公式 | 原纸单价、用纸总价、加工费用、税金、含税成本按 PRD 第 8.8-8.10 固化。 |
| 推荐硬规则 | 不得把不达标或不可生产方案推荐为达标方案。 |
| 历史习惯 | 只能影响推荐排序和理由展示，不能修改计算结果、达标状态或设备状态。 |
| AI 边界 | AI 不参与核心计算，不反写计算结果，不编造没有数据支持的结论。 |
| 数据安全 | 真实订单、纸价、客户和原纸数据不得写入公开样例或测试快照，必要时必须脱敏。 |

## 10. 非功能要求

| 维度 | 要求 |
|------|------|
| 性能 | 单次方案生成目标不超过 5 秒。 |
| 易用性 | 主流程不超过 3 步：输入参数、生成方案、查看或导出。 |
| 可追溯 | 历史方案保存输入、价格快照、参数版本、推荐结果、调整状态和导出记录。 |
| 可维护 | 核心业务逻辑放在 `src/modules/` 对应模块中，页面只做展示和触发。 |
| 可测试 | 公式、推荐、原纸代码映射、历史订单和导入导出等高风险能力必须有自动化测试。 |
| 安全 | 必须有登录保护、环境变量管理、数据库备份和导出备份能力；密钥不得暴露到客户端。 |

## 11. 成功标准

| 标准 | 判断方式 |
|------|----------|
| 业务闭环可用 | 用户能从基础数据维护开始，完成输入、推荐、调整、保存和导出。 |
| 计算口径一致 | 面积、强度、成本和设备限制与 PRD 固化公式一致。 |
| 方案可解释 | 每套方案能说明成本、安全、均衡等推荐依据，并展示不达标或不可生产原因。 |
| 数据可追溯 | 历史方案能回看当时输入、原纸价格快照、基础参数版本和调整状态。 |
| 边界不越界 | 批量配纸、复杂权限、供应商同步等非首版能力不提前混入 MVP。 |

## 12. 产品级验收标准

- 用户未维护纸厂、原纸或基础参数时，系统应阻止生成方案并提示先维护数据。
- 用户输入合法纸箱参数和生产数量后，系统应生成经济型、安全型、均衡型方案；若可用瓦型不足三种，应按实际可用数量展示并提示原因。
- 每套方案必须展示层数、瓦型、各层原纸、面积、含税成本、耐破、边压、空箱抗压、是否达标、是否可生产和选型理由。
- 经济型应优先选择满足硬规则前提下单箱含税成本最低的方案。
- 安全型应优先选择抗压富余率最高且不超过既定上限的方案。
- 均衡型应按成本和安全权重综合评分，默认权重为 50% 成本、50% 安全。
- 用户手动调整方案后，系统必须重新计算成本、强度和设备限制；计算值、达标状态和可生产状态不可手动编辑。
- 保存历史方案时，系统应保存输入参数、生产数量、原纸价格快照、基础参数版本、推荐方案结果、是否手动调整、导出记录和保存时间。
- AI 理由失败、超时或达到每日调用上限时，应使用模板理由，不阻断方案生成。
- 历史习惯参与推荐时，不得让未达标或不可生产方案变为达标或可生产。
