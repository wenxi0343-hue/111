# 纸箱自动配纸工具 PRD（V1.0）

## 文档信息

| 项目 | 内容 |
|------|------|
| 产品名称 | 纸箱自动配纸工具 |
| 文档版本 | V1.0 |
| 阶段 | 需求确认版 |
| 适用范围 | 单次纸箱配纸、成本核算、强度校核、方案导出 |
| 更新日期 | 2026-06-27 |

## 1. 产品定位

纸箱自动配纸工具面向纸箱厂工艺人员和销售业务员，用于客户询价、报价和打样前的单次配纸决策。

用户输入纸箱尺寸、内装物、堆码、生产数量等信息后，系统基于公司默认面积公式、强度公式、成本公式和原纸数据，自动生成多套配纸方案，并输出成本、耐破、边压、空箱抗压、是否达标和选型理由。

## 2. 目标用户

| 角色 | 核心诉求 |
|------|----------|
| 工艺人员 | 方案强度达标、计算口径清楚、参数可追溯 |
| 销售业务员 | 快速报价、方案可展示、可导出报告 |

## 3. V1.0 范围

### 3.1 首版包含

- 单次纸箱配纸方案生成
- 三套推荐方案：经济型、安全型、均衡型
- 纸厂、箱板纸、瓦纸数据维护
- Excel / CSV 批量导入原纸数据
- 公司默认面积、强度、成本公式
- 生产设备尺寸限制校验
- 手动调整推荐方案并重新校核
- 最近 50 条历史方案保存
- 完整配纸报告和精简方案表导出 PDF
- 原纸数据、公式/参数、历史方案导出备份

### 3.2 首版不包含

- 批量配纸
- 多用户和权限管理
- 供应商价格自动同步
- 客户信息关联
- 方案版本对比
- 摇盖类型选择及专项校验
- 戳穿强度、吸潮变形等其他物理风险指标计算

## 4. 使用流程

1. 用户维护纸厂、原纸、基础参数。
2. 用户输入纸箱参数、产品信息、堆码要求和生产数量。
3. 系统生成经济型、安全型、均衡型方案。
4. 用户查看成本、强度、达标状态和选型理由。
5. 用户可手动调整瓦型、层数、纸厂、克重等字段。
6. 系统重新计算并标记调整后的达标状态。
7. 用户导出报告或保存历史方案。

## 7. 配纸方案生成

### 7.1 方案类型

| 方案 | 策略 | 说明 |
|------|------|------|
| 方案 A 经济型 | 最低成本优先 | 满足最低强度要求前提下，单箱含税成本最低 |
| 方案 B 安全型 | 最高安全冗余 | 抗压富余率最大，富余率超过 200% 的方案排除 |
| 方案 C 均衡型 | 成本和安全综合评分 | 默认成本 50%、安全性 50%，支持设置中调整 |

### 7.2 层数推荐

| 层数 | 适用条件 | 瓦型要求 | 最低强度要求 |
|------|----------|----------|--------------|
| 三层 | 内装物承重 ≤ 20kg | A / B / C / E 单瓦型 | 空箱抗压 ≥ 400N，边压 ≥ 4.0kN/m |
| 五层 | 内装物承重 20-30kg，或易碎产品 | AB / AC / BC / BE | 空箱抗压 ≥ 800N，边压 ≥ 7.0kN/m |
| 七层 | 承重 ≥ 30kg 的重型产品 | BAC 为主 | 空箱抗压 ≥ 1200N，边压 ≥ 10.0kN/m |

承重边界值 20kg、30kg 支持设置中调整。当重量落在边界区间时，系统可同时生成相邻层数方案供对比。

### 7.3 瓦型推荐

| 层数 | 主要瓦型 | 次要瓦型 |
|------|----------|----------|
| 三层 | C、A、B | E |
| 五层 | BC、BA、AC | BE |
| 七层 | BAC | - |

系统生成的三套方案优先使用不同瓦型。若可用瓦型不足三种，按实际可用数量生成，并提示当前原纸数据中瓦型种类不足。

## 8. 计算规则

### 8.1 公式口径

V1.0 内置公司默认公式，覆盖面积、耐破、边压、空箱抗压和成本计算。后续版本可支持管理员维护或导入公式。

### 8.2 面积公式

统一约定：

- 用户输入的 L、W、H 为纸箱内径，单位 mm。
- 面积计算直接使用输入内径，不再按层数二次扣减尺寸。
- 单箱纸板面积 = 总长 × 总宽 ÷ 1000000，单位 m²。
- 搭舌由成箱方式决定。
- BE 瓦按三层箱面积公式计算。

| 层数 | 输入口径 | 总长 | 搭舌 | 总宽 | 摇盖 | 高 |
|------|----------|------|------|------|------|----|
| 三层普箱 | 长=L，宽=W，高=H | 搭舌+(长+4)+(宽+7)+(长+7)+(宽+4) | 粘箱35，钉箱40 | 摇盖×2+高 | 默认(宽+8)÷2；C/BE瓦为(宽+10)÷2 | 高+6 |
| 五层普箱 | 长=L，宽=W，高=H | 搭舌+(长+4)+(宽+8)+(长+8)+(宽+4) | 粘箱40，钉箱45 | 摇盖×2+高 | (宽+12)÷2 | 高+7 |
| 七层普箱 | 长=L，宽=W，高=H | 一片：45+(长+6)+(宽+10)+(长+10)+(宽+6)；两片：45+(长+6)+(宽+10) | 固定45 | 摇盖×2+高 | (宽+16)÷2 | 高+9 |

首版仅七层普箱支持两片成箱面积计算。三层、五层普箱若一片成箱超过设备最大宽度，直接标记为不可生产。

### 8.3 生产设备限制

| 设备/工序 | 限制项 | 数值 |
|-----------|--------|------|
| 生产纸板机器 | 最大纸板长 | 1800mm |
| 生产纸板机器 | 最大纸板宽 | 1710mm |
| 生产纸板机器 | 最小纸板长 | 500mm |
| 生产纸板机器 | 最小纸板宽 | 360mm |
| 印刷开槽机 | 最大进纸尺寸 | 2400×1580mm，2400 对应总长，1580 对应总宽，不允许换方向 |
| 印刷开槽机 | 最小进纸尺寸 | 600×360mm |
| 印刷开槽机 | 最大印刷面 | 2360×1200mm |
| 印刷开槽机 | 最小开槽间隔 | 230-65-230-65mm |
| 产品开槽尺寸 | 箱高 | ≤850mm |
| 产品开槽尺寸 | 单摇盖产品：摇盖+箱高 | ≤1257mm |
| 产品开槽尺寸 | 双摇盖产品：单边摇盖+箱高 | ≤1350mm |

### 8.4 强度公式

首版强度指标仅包含耐破、边压、空箱抗压。

| 项目 | 公式/规则 |
|------|-----------|
| 单层耐破强度 | 单层耐破 = 耐破指数 × 克重，结果按整数取值 |
| 平纸层环压强度 | 单层环压 = 横向环压指数 × 克重，结果按整数取值 |
| 瓦楞层环压强度 | 单层环压 = 横向环压指数 × 克重 × 瓦楞伸长系数，结果按整数取值 |
| 纸箱边压强度 | 边压强度 = 全部参与层位环压强度之和 × 修正系数 |
| 空箱抗压强度 | 空箱抗压 = 5.874 × 边压强度 × √(纸板厚度 × 纸箱周长 ÷ 1000000)，结果按整数取值 |
| 纸箱耐破强度 | 纸箱耐破 = 参与耐破层位的耐破强度之和 × 0.95 |

边压强度表内以 N/m 计算，界面展示为 kN/m 时换算为 N/m ÷ 1000。纸箱周长使用内径计算：纸箱周长 = (内长 + 内宽) × 2。

### 8.5 强度参与层位

| 指标 | 参与层位 |
|------|----------|
| 边压强度 | 面纸、里纸、所有瓦楞层、所有夹心/中隔纸层 |
| 耐破强度 | 面纸、里纸、夹心/中隔纸层；瓦楞层不计入耐破汇总 |

### 8.6 瓦楞伸长系数

| 瓦型 | 系数 |
|------|------|
| A 瓦 | 1.49 |
| B 瓦 | 1.33 |
| C 瓦 | 1.431 |
| E 瓦 | 1.329 |

### 8.7 纸板厚度

纸板厚度按瓦型从基础表取值；复合瓦型按所包含的单瓦厚度相加。

| 瓦型 | 厚度 |
|------|------|
| A 瓦 | 4.5mm |
| B 瓦 | 2.5mm |
| C 瓦 | 3.7mm |
| E 瓦 | 1.1mm |
| BC 瓦 | 6.2mm |
| BA 瓦 | 7.0mm |
| BE 瓦 | 3.6mm |
| AC 瓦 | 8.2mm |
| BAC 瓦 | 10.7mm |

### 8.8 成本公式

| 项目 | 公式/规则 |
|------|-----------|
| 平纸层单价 | 单层单价 = 原纸纸价 × 克重 ÷ 1000000 |
| 瓦楞层单价 | 单层单价 = 原纸纸价 × 克重 × 瓦楞系数 ÷ 1000000 |
| 用纸总价 | 用纸总价 = 各层单价合计 × 纸箱面积 ÷ 原纸利用率 |
| 加工费用 | 加工费用 = 层数费用系数 × 0.9 × 纸箱面积 ÷ 原纸利用率 |
| 税金 | 税金 = (垫板费用 + 加工费用 + 用纸总价) × 1.05 × 1.5% |
| 含税成本 | 含税成本 = 垫板费用 + 加工费用 + 税金 + 用纸总价 |
| 盈亏 | 盈亏 = 售价 - 含税成本 |
| 销售利润率 | 销售利润率 = 盈亏 ÷ 售价 |

成本计算中的瓦楞系数与瓦楞伸长系数保持一致，E 瓦按 1.329 计算。

### 8.9 原纸利用率

| 生产数量 | 原纸利用率 |
|----------|------------|
| < 200 | 0.8 |
| 200-2000 | 0.9 - (2000 - 生产数量) × 0.00005 |
| > 2000 | 0.9 + (生产数量 - 2000) × 0.00001，最高不超过 0.95 |

### 8.10 加工费用层数系数

| 层数 | 系数 |
|------|------|
| 三层 | 1.1 |
| 五层 | 1.36 |
| 七层 | 2.12 |

## 10. 方案调整

用户可在结果页面手动调整：

- 瓦型
- 纸箱层数
- 面纸、里纸、芯纸、瓦纸克重
- 纸厂

用户修改后，系统需重新计算耐破、边压、空箱抗压、成本和设备限制状态。计算值、是否达标、是否可生产、选型理由不可手动编辑。

修改后的方案覆盖原方案保存，并标记为“用户已手动调整”。

## 11. 历史方案

首版保存最近 50 条历史方案。每条历史方案至少保存：

- 输入参数
- 生产数量
- 原纸价格快照
- 基础参数版本
- 推荐方案结果
- 是否手动调整
- 导出记录
- 保存时间

## 12. AI 选型理由

AI 选型理由根据输入参数、方案配置、计算结果和方案定位生成。

选型理由必须覆盖：

1. 方案核心优势：成本最低、安全最高或综合最优。
2. 纸板组合特性。
3. 空箱抗压校核结果和富余率。
4. 边压强度是否满足堆码和运输需求。
5. 耐破强度是否满足运输颠簸需求。
6. 适用场景建议。

AI 不得编造没有数据支持的结论。若某项没有计算依据，应显示“暂无数据支持判断”。

AI 调用失败、超时、达到每日调用上限时，使用固定模板生成选型理由，不阻断方案生成。

## 13. 输入校验

| 规则 | 要求 |
|------|------|
| 纸箱内长 L | 100-2000mm |
| 纸箱内宽 W | 100-1500mm |
| 纸箱内高 H | 100-1500mm |
| 内装物重量 | 0.5-100kg |
| 堆码层数 | 1-30 层 |
| 尺寸合理性 | 内长 ≥ 内宽，内长/内宽在 1.0-5.0 之间 |
| 生产数量 | 必须大于 0 |
| 数据完整性 | 至少有纸厂、箱板纸、瓦纸、基础参数 |

## 14. 异常处理

| 场景 | 处理 |
|------|------|
| 纸厂或原纸数据为空 | 阻止生成方案，提示先维护数据 |
| 所有方案均不达标 | 正常生成方案，标记未达标并说明原因 |
| 可用瓦型不足三种 | 按实际可用数量生成，并提示瓦型不足 |
| 三层、五层一片成箱超过最大纸板宽 | 标记不可生产（超过设备最大宽度限制） |
| 七层两片成箱后仍超过最大纸板宽 | 标记不可生产（超过设备最大宽度限制） |
| 用户调整后不达标 | 标红不达标字段并提示 |
| 公式或基础参数缺失 | 阻止生成方案，提示检查公式/参数配置 |
| AI 调用失败 | 使用模板选型理由 |

## 15. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 单次方案生成 ≤ 5 秒 |
| 易用性 | 主流程不超过 3 步：输入参数 → 生成方案 → 查看/导出 |
| 数据持久化 | 自动保存最近 50 条历史方案 |
| 数据安全 | 支持原纸、公式/参数、历史方案导出备份 |
