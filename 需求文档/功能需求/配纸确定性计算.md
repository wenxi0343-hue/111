# 配纸确定性计算 — 功能需求说明书

## 1. 背景与价值

**为什么做**：面积、强度、成本和设备限制是配纸工具可信度的核心。用户只有看到稳定、可追溯、符合公司口径的计算结果，才能判断某个配纸方案是否可生产、是否达标、成本是否可用于报价。如果这些计算口径不清晰，后续推荐、手动调整、历史保存和导出报告都会失去依据。

**做成什么样**：用户输入合法纸箱参数并具备完整基础数据后，系统按 PRD 固化口径完成面积、设备限制、强度和成本计算；推荐区只展示达标且可生产的方案；不进入推荐的候选只在结果页展示汇总原因，不展示不可推荐候选明细。

**关联**：`specs/开发路线图.md` Milestone 1 / Phase 1.3 / 面积计算、强度计算、成本计算；对应业务能力为确定性计算。

## 2. 范围

### 本次做

- 按 PRD 第 8.2 固化口径计算三层、五层、七层普箱面积。
- 按 PRD 第 8.2 固化口径支持七层普箱两片成箱面积计算。
- 按 PRD 第 8.3 固化口径判断生产设备限制。
- 按 PRD 第 8.4-8.7 固化口径计算耐破、边压、空箱抗压。
- 按 PRD 第 8.8-8.10 固化口径计算原纸利用率、用纸总价、加工费用、税金和含税成本。
- 推荐前执行硬规则过滤，推荐区只展示达标且可生产的方案。
- 设备不可生产的候选不进入推荐，直接显示设备不可生产原因，不继续强度和成本计算。
- 强度不达标的候选不进入推荐，但继续展示已计算出的面积、强度和成本。
- 数据不足或参数异常的候选不进入推荐，只展示缺失或异常原因，不继续后续计算。
- 推荐方案不足三套时，展示不推荐原因汇总，不展示不可推荐候选明细。
- 生成结果摘要不显示堆码承重状态，改为显示计算后的纸板面积。
- 同一个候选存在多个问题时，展示全部已识别原因。

### 本次不做

- 不新增堆码抗压目标公式，首版只按 PRD 已明确的层数最低强度要求判断。
- 不从 Excel 成本表、纸价表或历史订单表反推新公式。
- 不做批量配纸。
- 不做摇盖类型选择或摇盖专项校验。
- 不计算戳穿强度、吸潮变形等其他物理风险指标。
- 不做 AI 选型理由生成。
- 不做推荐排序策略本身，经济型、安全型、均衡型排序在后续推荐功能中处理。

## 4. 需求详述

### 4.1 核心流程

1. 用户在配纸输入页面填写合法纸箱参数、产品信息、生产数量和可选堆码层数。
2. 用户点击生成方案。
3. 系统检查纸厂、箱板纸、瓦纸和基础参数是否具备生成方案所需的整体数据。
4. 整体基础数据完整时，系统生成候选配纸组合。
5. 系统先检查候选是否具备必要数据和参数。
6. 数据和参数完整的候选先进行面积计算和设备限制判断。
7. 设备不可生产的候选直接进入不推荐结果并参与汇总，不继续强度和成本计算。
8. 设备可生产的候选继续计算强度和成本。
9. 强度不达标的候选进入不推荐结果，并在评估结果中保留已计算出的面积、强度和成本。
10. 达标且可生产的候选进入后续推荐选择范围。
11. 推荐区展示达标且可生产的经济型、安全型、均衡型方案；不足三套时展示原因汇总，不展示不可推荐候选明细。

### 4.2 交互规则

- 推荐区只展示达标且可生产的方案。
- 推荐方案少于三套时，应在结果页展示推荐不足的汇总原因。
- 汇总原因应按原因类型展示数量，例如数据不足、参数异常、设备不可生产、强度不达标。
- 生成结果页不展示不进入推荐的候选明细，避免结果过于臃肿。
- 生成结果页顶部摘要展示计算面积；如暂无可用面积结果，显示“暂无面积结果”。
- 生成结果页顶部摘要不展示堆码承重状态，堆码层数仍可作为输入参与后续判断。
- 同一个候选的多个问题应在评估结果中保留，并全部计入汇总统计。
- 设备不可生产、强度不达标、数据不足或参数异常的具体原因可用于推荐槽位、汇总统计和后续诊断，但不在生成页单独展开候选列表。
- 如果推荐区为空，应明确提示当前没有达标且可生产的推荐方案。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 面积计算必须按 PRD 第 8.2 固化公式执行。 |
| BR-002 | 生产设备限制必须按 PRD 第 8.3 固化参数和方向要求执行。 |
| BR-003 | 强度计算必须按 PRD 第 8.4-8.7 固化规则执行。 |
| BR-004 | 成本计算必须按 PRD 第 8.8-8.10 固化规则执行。 |
| BR-005 | 推荐区不得展示未达标或不可生产的方案。 |
| BR-006 | 纸厂、箱板纸、瓦纸或基础参数整体缺失时，应阻止生成方案。 |
| BR-007 | 单个候选缺少必要数据或参数时，该候选不进入推荐，且不继续后续计算。 |
| BR-008 | 候选不满足设备限制时，该候选不进入推荐，且不继续强度和成本计算。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 完整数据下完成确定性计算
  - **Given** 用户输入合法纸箱参数，且纸厂、箱板纸、瓦纸和基础参数完整
  - **When** 用户点击生成方案
  - **Then** 系统按 PRD 固化口径计算面积、设备状态、耐破、边压、空箱抗压和含税成本

- [ ] **AC-002**: 推荐区只展示达标且可生产方案
  - **Given** 系统已完成候选计算和判断，且存在达标并可生产的候选
  - **When** 系统展示推荐结果
  - **Then** 推荐区只展示达标且可生产的经济型、安全型、均衡型方案

- [ ] **AC-003**: 强度不达标候选仍保留已计算结果
  - **Given** 某候选设备可生产，但空箱抗压、边压或耐破中至少一项不达标
  - **When** 系统完成候选评估
  - **Then** 评估结果保留该候选的面积、强度、成本和具体不达标指标，并标记“不进入推荐：强度不达标”

- [ ] **AC-004**: 推荐不足时展示汇总原因
  - **Given** 达标且可生产的候选不足三套
  - **When** 系统展示结果页
  - **Then** 系统展示推荐不足的汇总原因，并按原因类型显示数量

- [ ] **AC-005**: 生成结果页不展示候选明细
  - **Given** 存在不进入推荐的候选
  - **When** 用户点击生成方案并查看结果页
  - **Then** 系统不展示“不可推荐候选明细”区域，只展示不推荐原因汇总和推荐槽位内必要原因

- [ ] **AC-023**: 生成结果摘要显示计算面积
  - **Given** 用户输入合法纸箱参数，且系统生成至少一个带面积结果的推荐或参考方案
  - **When** 用户点击生成方案并查看结果页
  - **Then** 生成结果摘要显示“计算面积”和面积值，不显示“堆码承重”摘要

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-006**: 整体基础数据缺失
  - **Given** 纸厂、箱板纸、瓦纸或基础参数整体缺失
  - **When** 用户点击生成方案
  - **Then** 系统阻止生成方案，并提示先维护对应基础数据

- [ ] **AC-007**: 单个候选缺少必要数据
  - **Given** 某候选缺少纸价、克重、强度指标、瓦楞系数、纸板厚度或层数费用系数等必要项
  - **When** 系统处理该候选
  - **Then** 该候选不进入推荐，评估结果保留具体缺失原因，不继续强度和成本计算

- [ ] **AC-008**: 设备不可生产候选不继续计算
  - **Given** 某候选不满足生产设备限制
  - **When** 系统完成设备限制判断
  - **Then** 该候选不进入推荐，评估结果保留具体设备不可生产原因，不继续强度和成本计算

- [ ] **AC-009**: 多个不推荐原因全部计入汇总
  - **Given** 某候选存在多个已识别问题
  - **When** 系统生成不推荐原因汇总
  - **Then** 系统按原因类型统计该候选的全部原因，而不是只统计第一条原因

- [ ] **AC-010**: 所有候选都不满足推荐条件
  - **Given** 没有任何候选同时满足达标且可生产
  - **When** 系统展示结果页
  - **Then** 推荐区为空，并提示当前没有达标且可生产的推荐方案，同时展示不推荐原因汇总，不展示不可推荐候选明细

- [ ] **AC-011**: 设备限制说明具体超限项
  - **Given** 某候选因设备限制不进入推荐
  - **When** 系统记录不推荐原因
  - **Then** 系统保留具体不满足的限制项，例如纸板长宽超限、进纸尺寸超限、印刷面超限、开槽间隔不满足或箱高超限

- [ ] **AC-012**: 强度不达标说明具体指标
  - **Given** 某候选设备可生产但强度不达标
  - **When** 系统记录不推荐原因
  - **Then** 系统保留具体不达标指标，包括空箱抗压不足、边压不足或耐破不足；如多项不足，应全部保留

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-013**: 面积公式按 PRD 固化 ← BR-001
  - **Given** 任意三层、五层或七层普箱候选
  - **When** 系统计算纸板面积
  - **Then** 系统按 PRD 第 8.2 的内径输入、总长、搭舌、总宽、摇盖和高规则计算面积

- [ ] **AC-014**: 设备限制按 PRD 固化 ← BR-002
  - **Given** 任意候选完成面积计算
  - **When** 系统判断是否可生产
  - **Then** 系统按 PRD 第 8.3 的纸板机器、印刷开槽机、印刷面、开槽间隔和箱高限制判断，并且不允许调换进纸方向

- [ ] **AC-015**: 强度公式按 PRD 固化 ← BR-003
  - **Given** 任意设备可生产且数据完整的候选
  - **When** 系统计算耐破、边压和空箱抗压
  - **Then** 系统按 PRD 第 8.4-8.7 的参与层位、瓦楞伸长系数、纸板厚度和单位规则计算并展示结果

- [ ] **AC-016**: 成本公式按 PRD 固化 ← BR-004
  - **Given** 任意设备可生产且数据完整的候选
  - **When** 系统计算成本
  - **Then** 系统按 PRD 第 8.8-8.10 的原纸单价、原纸利用率、加工费用、税金和含税成本规则计算并展示结果

- [ ] **AC-017**: 未达标或不可生产不得进入推荐 ← BR-005
  - **Given** 任意候选存在强度不达标、设备不可生产、数据不足或参数异常
  - **When** 系统生成推荐区内容
  - **Then** 该候选不得出现在经济型、安全型或均衡型推荐中

- [ ] **AC-018**: 设备不可生产停止后续计算 ← BR-008
  - **Given** 某候选已经被判定为设备不可生产
  - **When** 系统完成候选评估
  - **Then** 评估结果只保留设备不可生产原因，不包含该候选的后续强度和成本计算结果

- [ ] **AC-019**: 强度不达标继续展示结果 ← BR-009
  - **Given** 某候选设备可生产且完成强度和成本计算，但强度不达标
  - **When** 系统完成候选评估
  - **Then** 评估结果保留已计算出的面积、强度和成本，并标记该候选不进入推荐

- [ ] **AC-020**: 堆码层数不新增公式 ← BR-012
  - **Given** 用户填写了堆码层数
  - **When** 系统判断强度是否达标
  - **Then** 首版只按 PRD 已明确的层数最低强度要求判断，不新增未确认的堆码抗压目标公式

- [ ] **AC-021**: 样例差异不自动改公式 ← BR-013
  - **Given** Excel 表或样例数据与 PRD 固化公式结果不一致
  - **When** 用户或开发者发现差异
  - **Then** 系统或文档不得自动改变公式口径，应记录差异并等待用户确认

- [ ] **AC-022**: 本功能不扩大范围
  - **Given** 本功能完成后
  - **When** 检查功能交付内容
  - **Then** 不包含新增堆码抗压公式、Excel 反推公式、批量配纸、摇盖专项校验、戳穿强度、吸潮变形、AI 理由或推荐排序策略

## 附录：已确认口径

| 项目 | 口径 |
|------|------|
| 公式来源 | 面积、设备限制、强度、成本均按 PRD 第 8.2-8.10 固化。 |
| Excel 表用途 | 只作为后续样例核对来源，不反推或新增公式。 |
| 推荐准入 | 只有达标且可生产的候选才能进入推荐区。 |
| 推荐不足 | 展示汇总原因，不展示不可推荐候选明细。 |
| 多个原因 | 同一候选的全部已识别原因都要保留并计入汇总。 |
| 设备不可生产 | 保留具体设备原因，不继续强度和成本计算。 |
| 强度不达标 | 不进入推荐，但评估结果继续保留面积、强度和成本等已计算结果。 |
| 数据不足或参数异常 | 整体缺失阻止生成；单个候选缺失则保留缺失原因，不继续后续计算。 |
| 堆码层数 | 首版不新增堆码抗压目标公式，只按 PRD 已明确的层数最低强度要求判断。 |
| 结果摘要 | 显示计算面积，不显示堆码承重状态。 |
