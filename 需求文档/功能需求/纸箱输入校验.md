# 纸箱输入校验 — 功能需求说明书

## 1. 背景与价值

**为什么做**：纸箱输入是配纸方案生成的入口。尺寸、产品重量、生产数量和堆码要求会影响面积、强度、成本、设备限制和推荐结果。如果输入不完整或明显不合理，后续计算结果就会失真，用户也难以判断问题出在哪里。

**做成什么样**：用户填写纸箱参数、产品信息和订单信息后，系统能在生成方案前检查必填项、数值范围和尺寸合理性；错误能定位到具体字段。堆码层数作为可选项，用户填写时才纳入承重校核和推荐判断，未填写时承重显示为未校核，不影响方案生成。

**关联**：`specs/开发路线图.md` Milestone 1 / Phase 1.3 / 纸箱输入与校验；对应业务模块为 `box-spec`。

## 2. 范围

### 本次做

- 校验纸箱长度、宽度、高度、结构类型、成箱方式。
- 校验产品类型、内装物重量、内装物排列方式。
- 校验生产数量。
- 支持堆码层数作为可选输入。
- 当用户填写堆码层数时，将堆码承重因素纳入方案计算、达标判断和推荐结果。
- 当用户未填写堆码层数时，系统正常生成方案，承重/堆码项显示为未校核，不出现承重达标或不达标结论。
- 所有数值边界按包含边界处理。
- 输入错误时定位到具体字段，并提示允许范围或业务原因。
- 基础数据缺失时阻止生成方案，并提示先维护对应基础数据。

### 本次不做

- 不保留堆码总高度字段。
- 不做摇盖类型选择。
- 不做单摇盖、双摇盖等摇盖专项校验。
- 不计算戳穿强度、吸潮变形等其他质量指标。
- 不做批量配纸。
- 不调整面积、强度、成本或推荐公式本身。

## 4. 需求详述

### 4.1 核心流程

1. 用户进入配纸输入页面。
2. 用户填写纸箱长度、宽度、高度、结构类型和成箱方式。
3. 用户填写产品类型、内装物重量和内装物排列方式。
4. 用户填写生产数量。
5. 用户按需填写堆码层数；没有堆码要求时可以不填。
6. 用户点击生成方案。
7. 系统检查必填项、数值范围、尺寸合理性和基础数据完整性。
8. 输入合法时，系统继续生成配纸方案。
9. 未填写堆码层数时，方案不把堆码承重因素纳入计算、达标判断和排序；系统保留未校核状态供后续流程判断，但生成结果摘要不展示堆码承重项。
10. 填写堆码层数时，方案将堆码承重因素纳入计算、达标判断和推荐结果。

### 4.2 交互规则

- 必填字段为空时，应提示具体字段。
- 数值超出范围时，应提示具体字段和允许范围。
- 尺寸不合理时，应提示明确原因，例如长度不能小于宽度。
- 特殊要求为选填，不应因为未填写特殊要求而阻止生成方案。
- 堆码层数为选填，不应因为未填写堆码层数而阻止生成方案。
- 未填写堆码层数时，系统保留“承重未校核”状态，但结果页摘要不展示承重/堆码项。
- 填写堆码层数后，如果承重不达标，系统正常展示方案，并标记承重不达标及原因。
- 基础数据缺失时，应提示先维护纸厂、箱板纸、瓦纸或基础参数。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 纸箱长度 L 合法范围为 100-2000mm，包含边界值。 |
| BR-002 | 纸箱宽度 W 合法范围为 100-1500mm，包含边界值。 |
| BR-003 | 纸箱高度 H 合法范围为 100-1500mm，包含边界值。 |
| BR-004 | 内装物重量合法范围为 0.5-100kg，包含边界值。 |
| BR-005 | 堆码层数为选填；填写时合法范围为 1-30 层，包含边界值。 |
| BR-006 | 纸箱尺寸必须满足 L ≥ W，且 L/W 在 1.0-5.0 之间，包含边界值。 |
| BR-007 | 生产数量必须大于 0。 |
| BR-008 | 堆码总高度不作为首版输入字段。 |
| BR-009 | 未填写堆码层数时，承重不参与本次方案计算、达标判断和推荐排序。 |
| BR-010 | 填写堆码层数时，堆码承重因素必须纳入方案计算、达标判断和推荐结果。 |
| BR-011 | 生成方案前必须确认至少有纸厂、箱板纸、瓦纸和基础参数。 |

### 4.4 CR-001 前端输入调整

- 默认选择内径；用户可选择内径或外径，长、宽、高的标签对应当前选择。切换不自动改变已填写数字。
- 提供三层、五层、七层选择；当前页面默认三层；纸箱结构类型和堆码层数不在当前页面显示。
- 当前页面移除产品类型、内装物重量和内装物排列方式；后续位置和指标校验另行设计。
- 当前页面停用方案生成并说明原因；不得通过表单提交绕过停用状态。
- 后续已确认方向：外径换算内径时，三层、五层、七层的长宽高分别各减 8、10、14 mm，方案仅使用所选纸箱层数。换算及结果生成不属于本次交付。

### 4.5 CR-002 物理指标要求（前端阶段）

- 增加默认关闭的“物理指标要求”开关，关闭时隐藏指标输入；开启显示重量与堆码、强度要求两组。
- 显示空纸箱重量、内装物重量（暂用 kg）、堆码层数（层）、边压（kN/m）、耐破（单位待确认）和空箱抗压（N）；各项可单独填写。
- 关闭后再次开启保留之前输入；物理指标当前仅界面输入，不接入计算或校验；面积生成按 CR-003 执行。耐破单位和后续计算规则另行确定。

### 4.6 CR-003 按瓦型生成单箱面积

- 输入内径直接使用；输入外径时，三、五、七层的长宽高分别减 8、10、14 mm 后计算。
- 三层按 A、C、B、E，五层按 BC、BA、AC、BE，七层按 BAC 分别展示单箱面积。BE 按三层面积公式；七层按 PRD 的加放数值。
- 当前仅显示瓦型与面积，不展示原纸配比、成本、物理指标判断或正式推荐；不得暗示已通过设备或强度校验。
- 未输入有效尺寸或换算后内径不符合原有范围与比例时，不生成面积。修改相关输入后清除旧结果。

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 完整合法输入可生成方案
  - **Given** 用户填写了合法的纸箱长度、宽度、高度、结构类型、成箱方式、产品类型、内装物重量、排列方式和生产数量
  - **When** 用户点击生成方案
  - **Then** 系统允许继续生成配纸方案

- [ ] **AC-002**: 未填写堆码层数也可生成方案
  - **Given** 用户已填写其他必填字段，且未填写堆码层数
  - **When** 用户点击生成方案
  - **Then** 系统允许继续生成方案，并且推荐方案不包含堆码承重因素

- [ ] **AC-003**: 填写堆码层数后纳入承重判断
  - **Given** 用户已填写合法的堆码层数
  - **When** 用户点击生成方案
  - **Then** 系统将堆码承重因素纳入方案计算、达标判断和推荐结果

- [ ] **AC-004**: 未填写堆码层数时承重未校核
  - **Given** 用户未填写堆码层数
  - **When** 系统生成方案结果
  - **Then** 系统正常展示方案和强度计算值，内部保留承重未校核状态，结果页摘要不展示承重/堆码项，且不出现承重达标或不达标结论

- [ ] **AC-021**: 尺寸类型与输入标签
  - **Given** 用户打开纸箱输入页面
  - **When** 用户查看尺寸类型或切换内径、外径
  - **Then** 默认选择内径，长宽高标签随选择显示内或外，已输入数字不自动改变

- [ ] **AC-022**: 选择纸箱层数
  - **Given** 用户打开纸箱输入页面
  - **When** 用户选择纸箱层数
  - **Then** 可选择三层、五层或七层，默认三层；页面不显示纸箱结构类型和堆码层数

- [ ] **AC-023**: 移除当前页面的内装物输入
  - **Given** 用户查看纸箱输入页面
  - **When** 页面显示输入项
  - **Then** 不显示产品类型、内装物重量和内装物排列方式

- [ ] **AC-026**: 展开物理指标输入
  - **Given** 用户进入纸箱输入页面
  - **When** 用户打开物理指标要求
  - **Then** 默认关闭且不显示输入，开启后展示六个指标、分组及已确认单位，指标可单独填写

- [ ] **AC-027**: 收起后保留输入
  - **Given** 用户已打开物理指标要求并填写部分指标
  - **When** 用户关闭后再次打开开关
  - **Then** 指标在关闭时隐藏，再打开后保留已填写的值

- [ ] **AC-028**: 根据层数展示瓦型面积
  - **Given** 用户填写有效尺寸并选择纸箱层数
  - **When** 用户生成面积
  - **Then** 三层展示 A、C、B、E；五层展示 BC、BA、AC、BE；七层展示 BAC，分别计算单箱纸板面积，相同面积的瓦型合并显示，BE 单独显示，结果保留三位小数

- [ ] **AC-029**: 外径换算与指定公式
  - **Given** 用户输入有效外径并选择层数
  - **When** 用户生成面积
  - **Then** 尺寸按所选层数换算内径，BE 按三层公式、七层按需求文档加放数值计算

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-005**: 必填字段为空
  - **Given** 任一必填字段为空
  - **When** 用户点击生成方案
  - **Then** 系统阻止生成，并提示具体缺失字段

- [ ] **AC-006**: 数值字段超出允许范围
  - **Given** 纸箱长度、宽度、高度、内装物重量或生产数量超出允许范围
  - **When** 用户点击生成方案
  - **Then** 系统阻止生成，并提示具体错误字段和允许范围

- [ ] **AC-007**: 纸箱长度小于宽度
  - **Given** 用户填写的纸箱长度小于纸箱宽度
  - **When** 用户点击生成方案
  - **Then** 系统阻止生成，并提示“纸箱长度必须大于或等于宽度”

- [ ] **AC-008**: 长宽比例不合理
  - **Given** 用户填写的长度/宽度比例小于 1.0 或大于 5.0
  - **When** 用户点击生成方案
  - **Then** 系统阻止生成，并提示尺寸比例不合理

- [ ] **AC-009**: 堆码层数超出允许范围
  - **Given** 用户填写了堆码层数，但层数小于 1 或大于 30
  - **When** 用户点击生成方案
  - **Then** 系统阻止生成，并提示堆码层数允许范围为 1-30 层

- [ ] **AC-010**: 填写堆码层数后承重不达标
  - **Given** 用户填写了堆码层数，且生成出的方案承重不达标
  - **When** 系统展示方案结果
  - **Then** 系统正常展示方案，并标记承重不达标及原因

- [ ] **AC-011**: 基础数据缺失
  - **Given** 纸厂、箱板纸、瓦纸或基础参数缺失
  - **When** 用户点击生成方案
  - **Then** 系统阻止生成，并提示先维护对应基础数据

- [ ] **AC-024**: 生成入口暂不可用
  - **Given** 用户处于本次前端调整阶段
  - **When** 用户尝试点击生成方案或通过表单提交
  - **Then** 页面提示生成暂不可用，不发起方案生成

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-012**: 边界值按合法输入处理
  - **Given** 用户输入数值正好等于允许范围边界
  - **When** 用户点击生成方案
  - **Then** 系统按合法输入处理

- [ ] **AC-013**: 纸箱尺寸范围 ← BR-001, BR-002, BR-003
  - **Given** 任意纸箱输入场景
  - **When** 系统检查尺寸
  - **Then** 纸箱长度范围为 100-2000mm，宽度范围为 100-1500mm，高度范围为 100-1500mm，且均包含边界值

- [ ] **AC-014**: 内装物重量范围 ← BR-004
  - **Given** 任意产品输入场景
  - **When** 系统检查内装物重量
  - **Then** 合法范围为 0.5-100kg，且包含边界值

- [ ] **AC-015**: 堆码层数范围 ← BR-005
  - **Given** 用户填写了堆码层数
  - **When** 系统检查堆码层数
  - **Then** 合法范围为 1-30 层，且包含边界值

- [ ] **AC-016**: 生产数量要求 ← BR-007
  - **Given** 任意订单输入场景
  - **When** 系统检查生产数量
  - **Then** 生产数量必须大于 0

- [ ] **AC-017**: 堆码总高度不保留 ← BR-008
  - **Given** 用户填写纸箱输入信息
  - **When** 用户查看堆码相关输入项
  - **Then** 系统只提供堆码层数字段，不提供堆码总高度字段

- [ ] **AC-018**: 未填写堆码层数不参与承重判断 ← BR-009
  - **Given** 用户未填写堆码层数
  - **When** 系统生成和展示推荐方案
  - **Then** 承重不参与本次方案计算、达标判断和推荐排序，且结果中承重/堆码项显示为未校核

- [ ] **AC-019**: 填写堆码层数必须参与承重判断 ← BR-010
  - **Given** 用户填写了合法的堆码层数
  - **When** 系统生成和展示推荐方案
  - **Then** 承重必须参与本次方案计算、达标判断和推荐结果

- [ ] **AC-020**: 本功能不扩大范围
  - **Given** 本功能完成后
  - **When** 检查功能交付内容
  - **Then** 不包含堆码总高度、摇盖类型选择、摇盖专项校验、戳穿强度、吸潮变形或批量配纸能力

---

- [ ] **AC-025**: 当前阶段不接入换算和计算
  - **Given** 用户选择外径及任一纸箱层数
  - **When** 用户编辑尺寸或切换选项
  - **Then** 页面不执行内外径换算，也不生成或展示新的计算、强度达标或推荐结论
