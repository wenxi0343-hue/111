# 导出备份能力 — 功能需求说明书

## 1. 背景与价值

**为什么做**：配纸工具首版会保存最近 50 条历史配纸方案。用户需要把这些已保存方案一次性导出留底，便于本地备份、业务复盘和后续查阅。如果只依赖系统内历史列表，一旦环境迁移或需要离线核对，就缺少方便携带的方案备份文件。

**做成什么样**：用户在历史方案列表点击“导出全部配纸方案”，系统将当前已保存的全部历史配纸方案导出为 Excel。该备份文件用于方案业务留底，不用于客户沟通，也不作为完整成本备份，因此不包含内部成本和原纸价格快照。导出成功后，相关历史方案的导出记录中新增“全部方案备份导出”和导出时间。

**关联**：`specs/开发路线图.md` Milestone 2 / Phase 2.3 / 导出备份能力；本需求仅保留“历史配纸方案 Excel 备份”部分，不包含原纸资料、公式/参数导出或恢复导入。

---

## 2. 范围

### 本次做

- 在历史方案列表支持导出当前全部已保存配纸方案。
- 导出格式为 Excel。
- 导出范围为当前系统实际保留的全部历史方案，最多最近 50 条。
- 导出内容包含输入参数、生产数量、原始推荐方案、最终确认方案、强度校核、达标状态、可生产状态、是否手动调整、基础参数版本、保存时间和导出记录。
- 导出内容不包含内部成本和原纸价格快照。
- 当前无历史方案时，不生成空文件，并提示暂无可导出的配纸方案。
- 导出失败时，提示导出失败，历史方案内容保持不变。
- 导出成功后，相关历史方案的导出记录中记录“全部方案备份导出”和导出时间。
- 导出文件名包含“配纸方案备份”和导出时间。

### 本次不做

- 不导出单条方案。
- 不做筛选导出。
- 不导出原纸资料。
- 不导出公式或基础参数。
- 不做备份文件恢复导入。
- 不包含单箱含税成本、各层单价、用纸总价、加工费用、税金和原纸价格快照。
- 不做客户信息关联、文件外部发送或自动归档。

## 4. 需求详述

### 4.1 核心流程

1. 用户进入历史方案列表。
2. 页面展示当前系统已保存的历史配纸方案。
3. 用户点击“导出全部配纸方案”。
4. 系统检查当前是否存在可导出的历史方案。
5. 若存在历史方案，系统生成 Excel 备份文件。
6. 用户获得文件名包含“配纸方案备份”和导出时间的 Excel 文件。
7. 导出成功后，相关历史方案的导出记录中新增“全部方案备份导出”和导出时间。
8. 若当前没有历史方案或导出失败，系统给出明确提示，不改变历史方案内容。

### 4.2 交互规则

- 导出入口位于历史方案列表。
- 导出操作针对当前系统中实际保留的全部历史方案。
- 历史方案为空时，不生成空 Excel 文件。
- 导出成功后，应给用户明确的成功反馈。
- 导出失败时，应提示导出失败，并保留历史方案内容不变。
- 导出文件名应能体现这是配纸方案备份，并包含导出时间。
- 导出成功后，历史方案详情或导出记录区域应能看到“全部方案备份导出”和对应时间。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | “导出全部配纸方案”的导出范围是当前系统实际保留的全部历史方案，最多最近 50 条。 |
| BR-002 | 本功能只导出已保存历史方案，不导出当前未保存的临时试算方案。 |
| BR-003 | Excel 备份文件不得包含内部成本和原纸价格快照。 |
| BR-004 | Excel 备份文件允许包含输入参数、生产数量、方案配置、强度、状态、基础参数版本、保存时间和导出记录。 |
| BR-005 | 历史方案为空时不生成空文件。 |
| BR-006 | 导出失败不得修改或删除任何历史方案内容。 |
| BR-007 | 导出成功后，所有本次导出的历史方案都应新增“全部方案备份导出”记录和导出时间。 |
| BR-008 | 本功能不承担恢复导入职责，备份文件仅用于本地留底、查看和人工复核。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 导出全部历史方案
  - **Given** 用户已保存至少一条历史配纸方案
  - **When** 用户点击“导出全部配纸方案”
  - **Then** 系统生成一个 Excel 文件，包含当前历史列表中的全部已保存方案

- [ ] **AC-002**: Excel 包含业务留底信息
  - **Given** Excel 导出成功
  - **When** 用户查看文件内容
  - **Then** 文件包含输入参数、生产数量、原始推荐方案、最终确认方案、强度、达标状态、可生产状态、是否手动调整、基础参数版本、保存时间和导出记录

- [ ] **AC-007**: 文件名便于识别
  - **Given** 用户成功导出全部配纸方案
  - **When** 用户查看文件名
  - **Then** 文件名包含“配纸方案备份”和导出时间

- [ ] **AC-008**: 导出成功后记录备份时间
  - **Given** 用户成功导出全部配纸方案
  - **When** 用户查看历史方案导出记录
  - **Then** 相关历史方案显示“全部方案备份导出”和导出时间

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-004**: 无历史方案时不生成空文件
  - **Given** 当前没有任何历史方案
  - **When** 用户点击“导出全部配纸方案”
  - **Then** 系统不生成空文件，并提示“暂无可导出的配纸方案”

- [ ] **AC-005**: 导出失败不影响历史内容
  - **Given** 导出过程中发生失败
  - **When** 用户查看页面
  - **Then** 系统提示导出失败，历史方案内容保持不变

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-003**: 不包含内部成本和原纸价格
  - **Given** Excel 导出成功
  - **When** 用户查看文件内容
  - **Then** 文件不包含单箱含税成本、各层单价、用纸总价、加工费用、税金和原纸价格快照

- [ ] **AC-006**: 导出范围为当前实际保留的全部历史方案
  - **Given** 历史方案最多保留最近 50 条
  - **When** 用户导出全部配纸方案
  - **Then** 导出范围为当前系统中实际保留的全部历史方案

- [ ] **AC-009**: 不导出未保存临时方案
  - **Given** 用户当前存在未确认保存的临时试算方案
  - **When** 用户导出全部配纸方案
  - **Then** 导出文件只包含已保存历史方案，不包含未确认保存的临时试算方案

- [ ] **AC-010**: 不扩大到其他备份范围
  - **Given** 本功能完成后
  - **When** 检查导出备份能力
  - **Then** 不包含原纸资料导出、公式/参数导出、筛选导出、单条方案导出或恢复导入
