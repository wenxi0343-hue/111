# 配纸工具纯配纸重构 — 功能需求说明书

## 1. 背景与价值

**为什么做**：当前项目原规划包含配纸计算、推荐、历史保存、导出，以及纸厂、原纸、纸价、基础参数、导入建库等数据维护能力。用户已经将基础资料维护放到后端资料库中处理，前台工具继续展示数据维护入口会增加使用负担，也容易让销售和工艺人员误以为可以在配纸工具中修改资料口径。

**做成什么样**：配纸工具重构为纯配纸工作台。用户只完成纸箱参数输入、生成经济型/安全型/均衡型方案、确认保存、查看历史方案、导出 PDF 和 Excel；所有数据维护、导入建库、资料编辑和方案手动调整能力都从前台移除。资料不完整时，工具只提示缺少的具体资料，方便用户到后端资料库补齐。

**关联**：覆盖 `specs/产品概述.md` 中 MVP 范围的“基础数据维护”前台入口，并调整 `方案确认与保存闭环`、`方案 PDF 导出` 中与手动调整和导出范围相关的口径。

---

## 2. 范围

### 本次做

- 保留纸箱参数输入能力。
- 保留经济型、安全型、均衡型三套方案生成能力。
- 保留从三套推荐中选择一套最终方案并确认保存。
- 保留历史方案列表。
- 历史方案列表只支持查看和导出，不支持删除、编辑或重新生成。
- 保留 PDF 导出。
- 新增或保留 Excel 导出，表格导出格式明确为 Excel。
- 移除所有前台数据维护入口。
- 移除用户手动调整方案和重新校核流程。
- 资料不完整时，提示缺少的具体资料项，方便到后端资料库补齐。

### 本次不做

- 不做纸厂、原纸、纸价、基础参数等资料的前台维护。
- 不做 Excel/CSV 导入建库。
- 不做原纸代码映射维护。
- 不做导出备份。
- 不做历史订单导入、历史习惯提取或历史习惯维护。
- 不支持用户手动调整瓦型、层数、纸厂、面纸、里纸、芯纸或瓦纸克重。
- 不支持方案调整后的重新校核。
- 不支持历史方案删除、编辑或重新生成。
- 不新增批量配纸、客户信息关联、方案版本对比或复杂审批。

## 4. 需求详述

### 4.1 核心流程

1. 用户进入配纸工具首页。
2. 页面展示纸箱参数输入、生成方案、历史方案等配纸相关入口。
3. 用户填写纸箱尺寸、产品信息、堆码要求和生产数量。
4. 用户点击生成方案。
5. 工具检查生成方案所需资料是否完整。
6. 资料完整时，工具生成经济型、安全型、均衡型三套方案。
7. 用户选择其中一套作为最终方案并确认保存。
8. 保存成功后，用户可在历史方案列表查看该方案。
9. 用户可从历史方案导出 PDF 或 Excel。
10. 资料不完整时，工具阻止生成正式推荐，并展示缺少的具体资料项。

### 4.2 交互规则

- 工具页面不展示纸厂维护、原纸维护、纸价维护、基础参数维护、导入建库、原纸代码映射或导出备份入口。
- 配纸结果页固定展示经济型、安全型、均衡型三个方案位置。
- 用户只能从系统生成的推荐方案中选择最终方案。
- 用户不能手动调整瓦型、层数、纸厂、面纸、里纸、芯纸或瓦纸克重。
- 页面不展示“待重新校核”状态，也不展示“重新校核”入口。
- 用户确认保存后，方案进入历史方案列表。
- 历史方案列表只允许查看方案详情、导出 PDF 和导出 Excel。
- 历史方案列表不允许删除、编辑或重新生成方案。
- 资料不完整时，页面应展示可理解的缺失清单，不提供前台补录或编辑入口。
- 导出 PDF 或 Excel 失败时，应提示导出失败，并保留历史方案内容不变。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 前台工具只保留配纸、历史查看和方案导出相关功能。 |
| BR-002 | 所有数据维护能力均不在前台工具中展示或操作。 |
| BR-003 | 推荐方案只能由系统根据当前资料生成，用户不得手动修改方案配置。 |
| BR-004 | 每次确认保存只能保存一套系统生成的最终方案。 |
| BR-005 | 历史方案列表只支持查看和导出，不支持删除、编辑或重新生成。 |
| BR-006 | 表格导出格式必须为 Excel，不使用 CSV 作为交付格式。 |
| BR-007 | 资料不完整时必须提示具体缺失项，不得只显示笼统的“资料不完整”。 |
| BR-008 | 缺失资料提示只用于指引后端资料补齐，不提供前台资料维护入口。 |
| BR-009 | 成本、强度、是否达标、是否可生产和推荐理由均为系统生成结果，不允许用户手动编辑。 |
| BR-010 | 配纸资料统一从 PostgreSQL 数据库 `paper_warehouse` 读取；服务端直接只读仓库表，不调用仓库后台 API。 |
| BR-011 | 推荐候选只使用 `paper_paperroll.status="in_stock"` 且能够完整映射纸种、等级、克重、价格和强度的原纸；其他记录不得进入正式推荐。 |
| BR-012 | 同一物料编码的在库卷纸按重量汇总，并按有效卷重计算加权吨价；强度指标继续按公司已确认的等级与克重标准确定性推导。 |
| BR-013 | `DATABASE_URL` 只能保存在服务端环境变量中，不得写入客户端代码、浏览器请求或版本库。 |
| BR-014 | 数据库连接不可用，或缺少启用纸厂、完整箱板纸、完整瓦纸、基础参数时，必须安全停止并列出具体缺失项。 |
| BR-015 | 原纸等级按名称确定性判定：纸种或规格带“进口”或“金太阳”为优等品；带“H级”或“AA级”为一等品；其余为合格品；优等品规则优先。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 进入纯配纸工作台
  - **Given** 用户已进入配纸工具
  - **When** 页面加载完成
  - **Then** 页面只展示纸箱参数输入、生成方案、历史方案和导出相关功能，不展示任何数据维护入口

- [ ] **AC-002**: 资料完整时生成三套方案
  - **Given** 用户填写了合法纸箱参数，且生成方案所需资料完整
  - **When** 用户点击生成方案
  - **Then** 页面展示经济型、安全型、均衡型三个方案位置，并显示每套方案的成本、强度、达标状态、可生产状态和推荐理由

- [ ] **AC-003**: 确认保存最终方案
  - **Given** 页面已生成经济型、安全型、均衡型方案
  - **When** 用户选择其中一套方案并点击确认保存
  - **Then** 系统保存该最终方案，并提示保存成功

- [ ] **AC-004**: 查看历史方案
  - **Given** 用户已经确认保存过方案
  - **When** 用户进入历史方案列表
  - **Then** 页面展示已保存方案，并允许用户查看方案详情

- [ ] **AC-005**: 导出 PDF
  - **Given** 用户在历史方案列表打开一条已保存方案
  - **When** 用户选择导出 PDF
  - **Then** 系统生成该历史方案对应的 PDF 文件

- [ ] **AC-006**: 导出 Excel
  - **Given** 用户在历史方案列表打开一条已保存方案
  - **When** 用户选择导出 Excel
  - **Then** 系统生成该历史方案对应的 Excel 文件

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-007**: 数据维护入口全部移除
  - **Given** 用户在工具中浏览所有页面和导航入口
  - **When** 用户查找纸厂、原纸、纸价、基础参数、导入建库、原纸代码映射或导出备份功能
  - **Then** 页面不展示这些功能入口，也不提供在前台新增、编辑或导入资料的操作

- [ ] **AC-008**: 原纸资料缺失时提示具体项
  - **Given** 某个候选方案所需原纸缺少纸价、克重、强度指标、适用瓦型或启用状态等资料
  - **When** 用户点击生成方案
  - **Then** 页面阻止生成正式推荐，并显示缺少的具体原纸资料项

- [ ] **AC-009**: 基础参数缺失时提示具体类别
  - **Given** 生成方案所需的瓦楞系数、纸板厚度、费用系数、利用率分段或设备限制参数缺失
  - **When** 用户点击生成方案
  - **Then** 页面阻止生成正式推荐，并显示缺少的具体参数类别

- [ ] **AC-010**: 不支持手动调整方案
  - **Given** 页面已生成推荐方案
  - **When** 用户查看方案详情
  - **Then** 页面不提供调整瓦型、层数、纸厂、面纸、里纸、芯纸或瓦纸克重的入口

- [ ] **AC-011**: 历史方案不可删除编辑或重新生成
  - **Given** 用户进入历史方案列表或历史方案详情
  - **When** 用户查看可用操作
  - **Then** 页面只提供查看、导出 PDF 和导出 Excel，不提供删除、编辑或重新生成操作

- [ ] **AC-012**: 导出失败提示
  - **Given** 用户正在导出历史方案 PDF 或 Excel
  - **When** 导出失败
  - **Then** 页面提示导出失败，并保留当前历史方案内容不变

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-013**: 前台只保留配纸能力 ← BR-001, BR-002
  - **Given** 本次重构完成
  - **When** 检查前台工具功能范围
  - **Then** 前台只包含配纸输入、方案生成、确认保存、历史查看、PDF 导出和 Excel 导出

- [ ] **AC-014**: 最终方案必须来自系统推荐 ← BR-003, BR-004
  - **Given** 用户准备确认保存方案
  - **When** 用户点击确认保存
  - **Then** 被保存的最终方案必须是系统生成的经济型、安全型或均衡型方案之一

- [ ] **AC-015**: 一次只保存一套最终方案 ← BR-004
  - **Given** 页面已生成三套推荐方案
  - **When** 用户确认保存
  - **Then** 系统一次只保存用户选择的一套最终方案，不同时保存多套最终方案

- [ ] **AC-016**: 表格导出必须为 Excel ← BR-006
  - **Given** 用户选择表格导出
  - **When** 导出成功
  - **Then** 用户得到的是 Excel 文件，而不是 CSV 文件

- [ ] **AC-017**: 缺失资料提示不可笼统 ← BR-007, BR-008
  - **Given** 生成方案所需资料不完整
  - **When** 页面展示缺失提示
  - **Then** 提示内容必须能让用户判断需要在后端资料库补齐哪类资料或哪项参数，不得只显示“资料不完整”

- [ ] **AC-018**: 计算结果不可手动编辑 ← BR-009
  - **Given** 任意推荐方案或历史方案详情
  - **When** 用户查看成本、强度、是否达标、是否可生产或推荐理由
  - **Then** 这些结果均为只读展示，用户不能手动编辑

- [ ] **AC-019**: 从 `paper_warehouse` 读取配纸资料 ← BR-010
  - **Given** 服务端已配置可用的 `DATABASE_URL`，且当前数据库为 `paper_warehouse`
  - **When** 用户生成配纸方案
  - **Then** 系统直接从 `paper_paperroll` 读取在库卷纸，不请求仓库后台 API

- [ ] **AC-020**: 只使用在库且映射完整的原纸 ← BR-011
  - **Given** 数据库同时存在 `in_stock`、车间余料、已出库或字段不完整的卷纸
  - **When** 系统读取可推荐原纸
  - **Then** 只有 `status="in_stock"` 且能够完整映射的原纸进入推荐候选

- [ ] **AC-021**: 聚合库存价格并使用公司强度标准 ← BR-012, BR-015
  - **Given** 同一物料有多卷在库记录，且规格能够按公司规则判定等级
  - **When** 系统生成可推荐原纸资料
  - **Then** 系统按卷重汇总并计算加权吨价，再按纸种、等级和克重推导耐破指数与横向环压指数

- [ ] **AC-025**: 原纸等级按公司规则判定 ← BR-015
  - **Given** 在库原纸的类别或规格分别包含“进口”“金太阳”“H级”“AA级”或其他文字
  - **When** 系统映射原纸等级
  - **Then** “进口”或“金太阳”为优等品，“H级”或“AA级”为一等品，其余为合格品；同时命中时优等品优先

- [ ] **AC-022**: 数据库资料缺失时精确提示 ← BR-014
  - **Given** 数据库缺少启用纸厂、完整箱板纸、完整瓦纸或基础参数
  - **When** 用户生成配纸方案
  - **Then** 页面列出具体缺失的资料类别，且不生成正式推荐

- [ ] **AC-023**: 数据库配置或连接失败时安全停止 ← BR-010, BR-013
  - **Given** `DATABASE_URL` 未配置、凭证无效或 PostgreSQL 不可访问
  - **When** 用户生成配纸方案
  - **Then** 系统返回不含完整连接串、密码和堆栈的业务错误，不回退到仓库后台 API

- [ ] **AC-024**: 数据库连接信息不暴露给浏览器 ← BR-013
  - **Given** 服务端已配置 `DATABASE_URL`
  - **When** 用户打开页面并生成方案
  - **Then** 浏览器页面、客户端脚本、业务错误和浏览器请求中均不包含数据库连接串或密码

|------|------|
| 工具定位 | 纯配纸工作台，不再承担前台资料维护。 |
